## Hypothesis (one sentence)

The six info-class signals that exist in code but have never run in a frozen
eval (funding-rate, open-interest/taker-flow, macro/FRED, fear&greed, DVOL,
GDELT) are inert solely for lack of frozen historical series; building a
`series/` section into the walk-forward snapshots and serving it through a
bar-aligned `SeriesProvider` activates them, and the resulting information set
— positioning, sentiment, and macro state, orthogonal to OHLCV by construction
— changes the walk-forward distribution measurably (this version measures the
re-baseline; it does not yet tune anything on it).

## Scope (one feed build, not five — DEEP_REVIEW §3.4)

Extend `scripts/walk_forward_freeze.py` with `series/{source}/{key}.json`
daily series per window; add a `SeriesProvider` in replay serving frozen
series bar-aligned (V216 bar-time fence; **raises on out-of-range reads, never
wraps** — the c244568 lesson as a hard contract). Signals read the provider,
never the network (V215 guard stays authoritative).

1. **FRED** (VIX, DXY, T10Y2Y, EFFR) + **alternative.me F&G** (`?limit=0`, one
