## Hypothesis

V246 proved a single global (trail_keep, hold_win) pair moves pooled PnL
≈ +$627 but is forced to compromise across runtime regimes. The OFF ledgers
show the three runtime-regime trade pools are wildly different (normal: 241
trades, −$886 total; high_vol: 38, +$6,764; crisis: 64, +$31,570) and V246's
grid showed regime-heterogeneous deltas. Bet: letting each RUNTIME regime
(`normal` / `high_vol` / `crisis` — the causal, non-lookahead label) carry its
own (trail_keep_frac, max_hold_win, max_hold_lose) recovers the compromise
cost, clearing the pooled bar with room instead of by $2.

**Coupling-class declaration (required by V247_RULER.md §7):** exit-only /
low-coupling. Applicable ruler row: pooled 2·SE ≈ $625, recent SE ≈ $360.

## Mechanism

- Engine already parametrized (V246, dormant). New flag
  `exit_regime_adaptivity_enabled` + 9 per-regime fields (defaults = legacy
  literals 0.5/10/6 → OFF and unknown-regime behavior byte-identical).
- `run_training.py` pushes the current runtime regime into the engine once
  per cycle AFTER the cycle completes → marks at cycle t use regime(t−1)
  (1-cycle lag, strictly causal; cycle 1 uses `normal`).
- $0 scorer (`scripts/v248_exit_scorer.py`, extends the validated v2 exact
  bar-mark replay): replays the committed OFF ledgers with the SAME lag,
  reading the per-cycle regime series from each window's committed
  `signal_fingerprint.jsonl`. Per-regime OFAT sweep around the incumbent:
  trail_keep ∈ {0.25, 0.75}, hold_win ∈ {8, 14}, hold_lose ∈ {4} per regime,
  plus best-per-regime composition cells. Validation gate unchanged: the
  incumbent replay must reproduce ≥95% of (exit_cycle, pnl).
- Known scorer blind spot (V246 post-mortem): re-entry capital coupling.
  Mitigation shipped in V247 Phase 2 — the grid aggregator reports the
  open-key re-entry coupling counter, and the scorer's prediction is
  explicitly a point estimate, not a gate substitute.

## Pre-registered gates (β structure — FIXED before any result exists)

**Separator/scorer gate (no grid unless):** some per-regime combo predicts
pooled mean-Δ ≥ +$625 AND recent mean-Δ ≥ −$360 AND pooled level-p25 not
worsened. Otherwise verdict = REFUTED_AT_SCORING, $0 spent.

**Grid verdict — ADOPT iff ALL of:**
1. pooled mean-Δ ≥ **+$625** (the low-coupling-class 2·SE from V247_RULER.md)
2. seeded-bootstrap 95% CI on pooled mean-Δ excludes 0
3. recent mean-Δ ≥ **−$360** (no-regression floor, ≈1·SE one-sided; rejects a
   true −$900 recent regression with ~93% power)
4. **Gated tail metric (pre-named per V247 #1): LEVEL-p25.** No regime's
   level-p25 may worsen by more than **$250** vs OFF. Δ-p25 is REPORTED
   (dual-tail) but NOT gated — V245/V246 showed Δ-p25 penalizes reshuffling
   that tightens the actual outcome tail.
5. 0 determinism FAILs; OFF arm byte-identical to the V240 confirm cells
   (OFF cells are reused, not re-run — same protocol as V245/V246).

**Falsifier:** any of 1–4 fails → REFUTED under the V247 bars; flag stays
OFF; no bar renegotiation after results. If pooled lands in [+$400, +$625)
the result is logged as "inside noise, no adopt" — NOT as a near-miss queue
item (that queue pattern is what V247 existed to kill).
