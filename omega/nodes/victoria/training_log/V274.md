Same instrument, same manifest, same bars, opposite arm. This inversion is

## 1. Mechanism under test (no code changes)

`run_training.py:1105` gates the ONLY populate path for both `_signal_ics` and
`_regime_ics`:

```python
if _strat is not None and bool(getattr(_active_features, "ic_seed_weighting", False)):
    ...
    _strat.update_signal_ics(_seed_pooled)     # line 1152
    _strat.update_regime_ics(_seed_regime)     # line 1154
```

With `ic_seed_weighting=False` both dicts stay empty ⇒ in
`_compute_weighted_conviction` every `ic = self._signal_ics.get(k, 0.0)` is `0.0`,
every term is skipped by the `abs(ic) < 1e-4` continue, `total_ic == 0.0`, and
`strategy.py:1241` returns the **raw equal-weight composite**. `per_regime_ic_weighting`
is therefore **doubly inert** when `ic_seed_weighting=False`: its `_regime_ics`
lookup is guarded by `if _per_regime and self._regime_ics`, and `_regime_ics` can
only be populated inside the same gated block.

So the flag pair collapses to a single binary arm, and the IC-OFF arm is exactly the
equal-weight path. **Bounded scope honored:** V274 changes NO code. The only lever is
the `--features` JSON handed to `scripts/run_training.py`. `strategy.py`,
`omega/nodes/victoria/*`, and the walk-forward machinery are not touched.

## 2. Gates

### G0 — provenance (Phase 0, zero compute)

**Assertion:** determine, from the run record rather than the flag defaults, which arm
produced each of the 32 standing-baseline windows.

**Evidence required (all three, or G0 is INCONCLUSIVE):**

1. The committed grid script whose arm the standing baseline names
   (`data/standing_baseline.json:config` → V240 `universe_selective`) — read its
   feature JSON.
2. The per-cell on-disk artifact for **all 32** windows
   (`$OMEGA_AUDIT_OUTPUT_DIR/v240wf_<wid>_universe_selective_<gate>_determinism/summary.json`),
   which records the exact `features` string the cell ran with.
3. The per-cell PnLs from those same artifacts must reproduce the committed
   `data/standing_baseline.json` `distributions.per_family` means **to the cent**.
   If they don't, the artifacts are not the standing baseline's provenance and G0
   fails regardless of what the feature strings say.

**Verdicts:** `IC_ON` (≥1 of 32 cells ran `ic_seed_weighting` true or absent-and-defaulted)
/ `IC_OFF` (all 32 ran it explicitly false) / `MIXED` / `INCONCLUSIVE`.

### G4 — harness sanity (runs BEFORE G1/G2; a FAIL is an R4 STOP)

Re-run **three sentinel cells**, one per family, at the *committed* standing-baseline
feature string, and compare against the committed per-cell PnL:

| family | window | gate | committed PnL |
|---|---|---|---|
| crisis | `snap_wf_20240310` | crisis | (transcribed at run time from the v240 artifact) |
| trend | `snap_wf_20230912` | trend | (same) |
| recent | `snap_wf_20250305` | recent | (same) |

**Bar: each of the three within 1.0% of its committed per-cell PnL.**
**FAIL ⇒ R4 STOP.** The harness has drifted since 2026-07-10 and every downstream
number in this version is meaningless. Report the drift; do not proceed to Phase 1.

### G-DET — determinism

Every cell run in this version is run at N=2 via `scripts/check_determinism.sh`
(the same instrument the V240 grid used) at the same `--sleep` the V240 grid used
(`SLEEP=0`). **Bar: `pnl_spread == $0.00` and `trade_range == 0` on every cell.**
Any non-zero spread invalidates the corresponding Δ.

### G1 — family-mean survival (the headline)

Paired per-window Δ = **(other arm) − (standing baseline)** on the same window,
aggregated to a family mean, for crisis / trend / recent.

**Bar (fixed now, both directions of G0):**

> **PASS = every family's arm mean is within ±20% of that family's standing-baseline
> mean.** i.e. |mean_arm − mean_SB| ≤ 0.20 × |mean_SB|.
> **FAIL = any family outside ±20%.**

Family denominators, from `data/standing_baseline.json`:
crisis $598.53 (±$119.71), trend $2,996.92 (±$599.38), recent $29.64 (±$5.93).

**Reading the verdict depends on G0, and both readings are written down now:**

- **G0 = IC_ON.** The other arm is IC-OFF. PASS ⇒ the standing baseline survives its
  causal control; H3 was cosmetic in Victoria. FAIL ⇒ **the standing baseline
  collapses under causal IC** — the same defect class as V255.C, and every V### gated
  on "must not move the standing baseline" was measuring against a contaminated number.
- **G0 = IC_OFF.** The other arm is IC-ON, and the standing baseline is *already* the
  causal control. PASS ⇒ the H3 defect is small in Victoria: the campaign dodged a
  mechanism that would barely have moved the number anyway. FAIL ⇒ the H3 defect is
  **large**, the campaign's IC-OFF convention was load-bearing, and every result that
  did run IC-ON (§4) is quantitatively suspect by the measured margin.

**Recent's denominator is $29.64, so its ±20% band is ±$5.93 — narrower than any
honest resolution this manifest has.** This is stated now, before the run, and NOT
used later to excuse a recent FAIL. Recent's G1 result will be reported as the bar
says, *and* alongside the V247 MDE ($1,043 at n=10) so the reader can see that a
recent FAIL on the ±20% bar is essentially guaranteed by arithmetic and carries
almost no information. Crisis (±$120 vs MDE $1,565) has the same pathology in weaker
form. **Trend's ±$599 band against a $4,118 MDE is the only family where ±20% is even
close to a resolvable question, and it is still inside noise.** The ±20% bar is
therefore reported as the pre-registered bar it is, with the MDE comparison as the
honest second column — not as a replacement bar chosen after the fact.

### G2 — per-cell distribution

Per family, the paired per-window Δ distribution: **n, mean, sd, median, min, max,
count of cells whose sign flips, count of cells crossing the $0 per-cell floor**, and
the family mean-Δ against the V247 MDE recomputed at the actual n
(`MDE = 2.801585 · sd/√n`). Coupling class **declared now: `heavy`** — IC weighting
changes the conviction score of every candidate every cycle, i.e. it is
selection-changing, the V241-reasoning class. V247_RULER.md §4's own verdict on that
class ("heavy-coupling mechanisms are unmeasurable on this manifest, full stop") is
recorded as the prior, not discovered afterwards.

**G2 is reported, not gated.** Its job is to show whether any family has a systematic
shift and whether the Δ is concentrated in a few cells or spread across all of them.

### G3 — regime honesty

Family membership must come from `data/walk_forward_manifest.json` `windows[].regime`

window→family map is byte-identical between the two arms.** If any cell's family
assignment differs between arms, that is a second lookahead and the version stops to
report it.

- **STOP** if G4 fails (R4: harness drift), if G-DET fails on any Phase-0 cell, or if

## 5. Anti-Goodhart commitments

- **No partial-IC fishing.** If the measured Δ is large, that is the finding. V274
  does not queue a V274-2 to search for an IC variant that recovers a number. V272
  refused exactly this and so does V274.
- **`data/standing_baseline.json` is not edited by this version.** V274 measures
  against it. Moving it is a separate journal act with its own pre-registration.
- **The ±20% bar is not renegotiated after the result.** A −18% result PASSES as
  written even if it feels like a collapse; a +25% result FAILS even if it feels like
  an improvement. The pattern across the three families is the informative object,
  not any single number, and §2/G1 already records what makes each family's band
  weak — before the numbers exist.
- **No code changes.** `--features` only.
