## Pre-registration + falsifier

Per `LIVE_PAPER_SCOPE.md` §7, V250 is the first implementation task of the
live-paper MVP: build the feed layer (`feeds.py`) and prove one real ingestion
cycle end-to-end with all pollers exercised. The prior session's handoff
mandated a **retrospective** smoke (pull the last 3 UTC days — Fri 2026-07-10,
Sat 2026-07-11, Sun 2026-07-12 — through each poller) rather than a 72h
prospective wait: same falsifier surface (weekday + weekend + reproducibility) at
~0h wall-clock. **Note explicitly: retrospective covers the identical falsifier
surface as prospective** — weekend-staleness of macro feeds, weekday-freshness,
and past-date reproducibility are all observable in historical data pulled live.

**Recon correction (measure before asserting).** The handoff stated a prior V250
session "landed Phases 0-3 and pushed commits." **This was false** — `git log`
showed no V250 commits (HEAD was V249 `481b89f`), no V250 branch, no worktree, no
`omega/live_paper/`. Only `LIVE_PAPER_SCOPE.md` existed. V250 was therefore built
from scratch this session; `SESSION_STATE.json` was stale (pointed at V248).

**Pre-registered falsifiers (a live poller is wrong if):**

- **F1** — crypto feeds (OHLCV, funding, fear_greed) are NOT fresh (0d staleness)
  on all 3 days (crypto trades 24/7 incl. weekends).
- **F2** — VIX/DXY/yield are NOT stale on Sat+Sun and fresh on Fri (macro series
  publish on weekdays only).
- **F3** — Binance provider failover kicks in (indicates provider weakness).
- **F4** — live feed schema is not a superset of the frozen-manifest series schema
  (upstream API drift vs `data/frozen_series/*.json`).
- **F5** — a live poller resolves a frozen path (`data/frozen_*`,
  `data/frozen_series/`, snapshots, `macro_cache.db`) — determinism-safety breach.
- **F6** — re-fetching the same past dates yields a different content hash
  ("stability of the past").
- **F7** — cache files are not atomic + checksummed.
- **F8** — a restart mid-fetch corrupts a committed cache file.

### The MATIC finding (F1 true-positive — the smoke earned its keep)

`ohlcv_close_maticusdt` returned bars ending **2024-09-10** (668d stale). Confirmed
live: `MATICUSDT` klines stop 2024-09-10; **`POLUSDT` is fresh (2026-07-13)**. This
is the **MATIC→POL rebrand/delisting** (Sept 2024). The frozen series still carries
MATIC (from `data.binance.vision` monthly archives, which retain the delisted
symbol), so backtest is blind to it — but a live-paper run **cannot trade MATIC**.
This is precisely the class of silent live-vs-frozen drift the smoke exists to
catch. The V240-selective universe (defined with MATIC) needs a MATIC→POL remap or
a MATIC drop before any live accumulation. **Left unchanged this session** —
faithful to the V240-selective baseline; a universe change needs a reconciliation
check (V251), not a silent edit. This is the #1 V251 entry item.

## Observability-gap audit → V251 entry

1. **MATIC→POL universe drift (P0).** Live universe must remap MATICUSDT→POLUSDT
   (or drop MATIC). Untradeable live; invisible in frozen backtest. Blocks the
   V251 reconciliation for MATIC.
2. **Run-host provisioning (P0).** A production live-paper host needs (a) a real
   `FRED_API_KEY` (DGS2/DGS10/DTWEXBGS/VIXCLS — DEMO_KEY is rejected), and (b)
   GDELT egress (blocked `000` here). Until then DXY/VIX ride the Yahoo fallback
   and yield_curve/gdelt are dark.
3. **GDELT daily-tone series shape.** The DOC 2.0 `tonechart` endpoint is not
   dated; a proper daily tone series needs the GKG timeline API. `fetch_gdelt`
   currently only proves reachability. Wire the dated series in V251.
4. **funding history depth.** Binance fapi `fundingRate` served 13 days here
   (ample for as-of), but the quarterly freeze (V253) needs the deeper
   `data.binance.vision` archive path the frozen store used — verify before soak.
5. **Failover observability.** `FeedResult.failover` is recorded but the crypto
   pollers don't yet chain Bybit→Coinbase→Kraken (a Binance miss is currently a
   hard miss). Wire `DataResilienceLayer` failover into `feeds.fetch_ohlcv` for
   the soak (V252/V253) so a single-provider outage skips-cycle rather than fails.
