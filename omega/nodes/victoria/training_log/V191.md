## Hypothesis

When the macro stack is silent (VIX low, TDA smooth, basket_std at
floor), `funding_rate` movements still carry real edge — they reflect
crowded perp positioning. A *range-trading sub-strategy* + a
*funding-carry signal* should fire in exactly the flat-market
conditions where momentum/mean-rev/macro all abstain.

## Changes

- New `funding_carry_signal` (point-in-time funding z-score)
- New range-trading sub-strategy in the ensemble
- V191c override: funding-carry can fire even when other
  sub-strategies abstain
- V192 aggressive preset added as sibling

## Conclusion

⚠️ The components are correct but **the carry path is gated behind
`range_bound == 1.0`**, which rarely fires in practice. So the
funding-carry signal is computed but doesn't get into the composite
when we need it most.

This is the silent-override pattern again: a feature exists but a
gate upstream prevents it from contributing.
