## Hypothesis

Our three single-window gates (recent / trend / crisis) are **Goodharting one
window per regime**, hiding the true cross-window generalization of recent
overlays. V218.E is the existence proof: identical code flipped crisis
**−$2,863 → +$13,052** purely by swapping `snap_crisis_2022h1` ↔
`snap_crisis_2020q1` (~$16k between-window crisis variance). The bet: building a
**distributional (≥3-window-per-regime) eval harness** and re-measuring the
standing main + V227 + V229 across it **will change at least one verdict** — i.e.
the single-window numbers were window-luck, not generalizable edge.

This is a **pure instrument upgrade**: no `strategy.py` / signal / flag logic
change, so it **cannot move any PnL**. It only changes the *yardstick* — from a
point estimate to a per-regime mean ± spread.

cross-window spread is small (**< ~$2k**, contradicting V218.E's ±$16k) **AND**
**(b)** V227's +$630 and V229's +$1,428 reproduce within that spread on every
window — i.e. the single-window numbers were representative all along. Then the
3-gate set was adequate, and V232 ships Track B's RV-term-structure brake
**directly**. Else → distributional eval is the real unlock and V232 ships the
brake **measured on the distribution**.

## Harness extension (Track 2)

Cell model: `gate → window → arm ∈ {ON skew-gated, OFF all-OFF} → replicate r∈{1,2}`.
One `check_determinism.sh` invocation = one (gate, window, arm) cell = N=2
replicates + its own $0.00 verdict (atomic unit, unchanged). The new
window/arm/gate-aggregation layers live entirely in the orchestrator + aggregator.

- **Per-cell within-window $0.00 byte-identical determinism check** still required
  and still gating (the lower instrument is unchanged).
- **Determinism gate:** every (window, cell, replicate) must PASS independently;
  any single FAIL → aggregator exits 5 → distributional verdict blocked.
- **Parallelism:** `DATA_DIR = ROOT/data` is a hardcoded global (`run_training.py:167`)
  → concurrent in-checkout cells corrupt shared `data/*.db` + `signal_ic_history.json`.
  Safe `MAXP>1` requires git worktrees (matrix-mode). **Launch runs sequential
  (`MAXP=1`)** for unattended overnight robustness — the proven standing-grid pattern,
  zero wedge risk. Crisis-ordered-first so the binding crisis distribution completes
  before any interruption.
- **Recovery:** resumable manifest `data/v231_dist/grid_state.json` (skip cells whose
  `summary.json` exists + PASS) + SESSION_STATE `v231_dist` block + per-cell PID file.

**N=3 statistical framing:** N=3 **is a meaningful upgrade over N=1** for the one
question V231 exists to answer — a sign-and-spread yes/no generalization test
(3/3 same-sign ≈ p=0.125, suggestive). It **cannot** support a CI / t-test /
effect-size ranking (needs N≈10). Hence every bar is a sign-and-spread rule, not a
significance test, and every verdict carries an explicit "N=3, may not generalize"
caveat.
