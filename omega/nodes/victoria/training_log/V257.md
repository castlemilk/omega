## Goal

Freeze **historical per-asset on-chain flow data** in hermetic, reproducible form,
sufficient to build the V256 flow-primary composite signal. V256 stopped at Phase 0
because no such data is on disk (only a market-wide stablecoin aggregate). V257 is the
unblock: produce frozen `data/frozen_series/on_chain/` files that a loader can replay
offline exactly like the existing funding / OI / GDELT feeds.

## Deliverable per successful V257

1. **Frozen series** under `data/frozen_series/on_chain/{BTC,ETH}/`, one JSON per
   metric, matching the existing frozen-series schema
   (`{name, source, fetched_at_utc, frequency:"daily", first_date, last_date, n_obs,
   unit, series:{date→value}}`). Metrics, mapped to the V256 pre-declared 4:
   - `net_exchange_netflow.json` — signal #1 (exchange in/outflow)
   - `active_addresses.json` — signal #2 (active-address velocity; velocity = the
     signal builder differences/normalizes this)
   - `transaction_volume.json` — supporting network-usage series
   - `stablecoin_supply.json` — signal #4, **per-chain** (the cross-sectional shape
     `stablecoin_total_usd` lacks)
   - *(whale-cluster movement, signal #3, is Glassnode/Santiment-tier — the CM
     community MVP may not carry it; that is acceptable, see falsifier / 3-of-4 gate.)*
2. **`scripts/v257_freeze_on_chain.py`** — the freeze pipeline: hermetic (one network
   pull, then never touches the network on replay), reproducible, MD5-checked, writes
   each series + updates a manifest entry exactly like `v238_freeze_series.py`.
3. **`omega/nodes/on_chain_flow/loader.py`** — reads the frozen series (network-free),
   aligns to the walk-forward date index, exposes per-asset series to the (future)
   V256 signal builder. Platform-agnostic; lives under a project node dir, imports no
   strategy code.
4. **Byte-identity check** — re-freezing the same historical date range produces a
   **bit-identical MD5** per file. Enforced in-pipeline (compare against the recorded
   manifest MD5) and re-runnable as a check.

## Determinism / freeze discipline (inherited from V238/V240)

- Freeze-once: `series` covers a closed `[first_date, last_date]` range; replay reads
  files only, **never the network** (the V238 manifest `_note`).
- Canonical JSON serialization (sorted keys, fixed float repr) so MD5 is stable across
  runs and machines. Provider values pinned to a fixed precision on write.
- As-of integrity: only include a date's value if it was final as of the freeze — no
  provider back-revision leakage. On-chain metrics are provider-revised (R4 hazard from
  V254); the loader must treat the frozen snapshot as immutable ground truth and the
  freeze must record `fetched_at_utc`.
- `PYTHONHASHSEED`-independent output.

## Falsifier (pre-registered)

The V257 pipeline **FAILS** if either holds:
1. **Insufficient history** — the acquired series provide **< 3 years** of daily
   coverage for the assets in scope (BTC/ETH). Below 3 years there aren't enough
   independent windows to give V256 the independent-N it exists to manufacture.
2. **API instability / non-reproducibility** — the freeze pipeline **cannot produce
   byte-identical output on retry** over the same historical range (MD5 mismatch on
   re-freeze). A non-reproducible source is unusable for a hermetic backtest regardless
   of coverage.

A **partial success** is explicitly allowed and is the V256 reopen trigger: if the
pipeline delivers **≥ 3 of the 4** pre-declared V256 signals (with ≥3-year daily
history and reproducible MD5), that is sufficient. Signal #3 (whale-cluster movement)
being absent from the free CM community tier does **not** fail V257 as long as the
other 3 land — V256 reruns with the 3 available signals, as pre-registered.

## Reopen path

On successful V257 (3+ signals frozen, byte-identity confirmed):
[`V256.md`](V256.md) becomes **buildable**. V256 is then **rerun exactly as
pre-registered** — flow-primary composite over the available signals, cross-sectional
across the frozen universe, walk-forwarded and gated like the spot book. **No
redesign**: the signal set is whatever V257 delivered, but the strategy shape and gates
are the V256 pre-registration, not a post-hoc fit to the data that happened to arrive.
