## Hypothesis

**Named channel:** the V219 grid left the eval at 3/4 hermetic — `trend_OFF`
FAILs at **$596.91** spread. The per-field bisect (`scripts/per_field_diff.py`)
named the channel precisely: the *first and only* divergent field is cycle-3
**`basic_signals.value`**, |Δ| = 3.2e-18 — a **sub-ulp sign-flip around zero**
(r1 −2.67e-18 vs r2 +5.34e-19). Cleanly-non-zero cycles are byte-identical; only
the near-zero cycles split.

This is a **distinct** channel from V217's (Apple vecLib BLAS parallel-reduction
order — the BLAS pin is verified active+effective here, `run_training.py:55-64`).
It is an order-of-summation channel in the `basic_signals` composite reduction
that **surfaces only with real macro** (V219) and was **latent at macro=0** —
which is exactly why V217's 6/6 "byte-identical" eval missed it (0+0+…=0 is
order-insensitive; real dxy/yield_curve terms re-introduced non-zero
order-sensitive bits).

`trend_OFF` is the one boundary-adjacent cell where the sub-ulp noise flips a
single trade (27↔26 → $597). `recent_OFF` carries the **identical** $6.52 noise
with an unchanged 22/22 trade count — direct proof it is the same sub-ulp source,
not a larger channel, just crossing no decision boundary.

**Bet:** replace the order-sensitive `sum(...)` reductions in the `basic_signals`
composite path with **`math.fsum(...)`** (exact-rounded; returns the correctly-
rounded sum independent of input order → eliminates the order channel for free,
no stable-key sort needed). Pure eval-substrate fence; **no strategy change**,
live path byte-unchanged.

## Implementation choice — `math.fsum` over canonical-sort

Two options were on the table (V219 next-steps):
- **(a) canonical-sort** the composite contributors by a stable key before summing
  (the V211 basket_std/mean pattern), or
- **(b) `math.fsum`** the reductions.

Chose **(b)**. `fsum` is exact-rounded — it computes the full-precision sum and
rounds once, so the result is identical regardless of input order *without* needing
to invent or maintain a stable sort key. It is the surgical, lowest-churn fix and
the most robust (closes *any* permutation, not just the one we sorted against).

**Sites fenced (the active basic_signals composite reduction path):**
- `omega/nodes/victoria/victoria_node.py:960` — `raw_value = sum(composites)/len(composites)`
  the per-ticker→cross-ticker mean that *directly* produces `basic_signals.value`
  (the named divergent field). Primary site.
- `omega/nodes/victoria/signal_generation.py:_balanced_composite` (178, 181) — the
  per-ticker composite reduction that feeds `composites`. (The IC-weighted path
  `_ic_weighted_composite` is currently **inert** — empty `signal_ic_history.json`
  → falls back to `_balanced_composite` — so it is out of scope here; V221 will
  fsum it when it wires ICs live.)

## Methodology lesson — the FP-order audit pattern (third precedent)

V220 is the **third** time we have closed a floating-point summation-order channel
in this eval:
- **V211** — `basket_std` / `basket_mean` cross-sectional aggregations
  (`strategy.py:1722`/`:2130`) → two `sorted()` wraps.
- **V217** — Apple vecLib BLAS multi-threaded parallel-reduction order → pin BLAS
  to 1 thread before numpy load.
- **V220** — `basic_signals` composite mean → `math.fsum`.

Three precedents is a pattern, not a coincidence. **Skill update queued** (Step 8):
add an "FP-order audit pattern" section so future iterations, when a determinism
gate fails, **grep for unsorted FP summations (`sum(` / `+=` over dict/set/list
iteration of floats) as the default first check** before any deeper bisect.

## Conclusion — REFUTED (wrong sublayer), with a real partial win

**Falsifier #1 fired:** `trend_OFF` spread is **$2,851.45**, far above the $200
floor — the hypothesis "fsum closes trend_OFF to < $200" is **REFUTED**.

But the fence did exactly what it claimed *at its own layer* — and that is the
diagnostic that names the next channel:

1. **The entry-flip channel IS closed.** V219's `trend_OFF` was non-deterministic
   on **trade count** (27↔26 → the $596.91 boundary flip). V220's `trend_OFF` is
   now **26/26 — trade count is locked.** Same for `trend_ON` (26/26). The
   `math.fsum` fences at `victoria_node.py:965` and
   `signal_generation.py:_balanced_composite` (commits `78b2a0d`, pre-reg
   `fad28da`) eliminated the sub-ulp `basic_signals.value` sign-flip that was
   tipping a single boundary trade in/out. The entry *decision* is now
   permutation-invariant. That sub-layer is fixed and stays fixed.

2. **A larger sizing/exit PnL-magnitude channel is now exposed.** With trade count
   locked at 26/26, `trend_OFF` PnL still ranges **$697 → $3,549 ($2,851 spread)**
   — the **same 26 trades, the same entry/exit cycles, but different dollar PnL.**
   That can only come from **position sizing or exit-price computation**, not the
   entry decision (which is binary/threshold-clipped and now byte-stable). The fsum
   fence didn't *create* this — it *uncovered* it: while the entry channel was open,
   the 27↔26 flip dominated the spread and masked the magnitude channel underneath.
   Close the binary channel and the analog channel underneath becomes visible.

3. **`recent_OFF` regressed PASS→FAIL** ($6.52 PASS at V219 → **$1,167.96 FAIL**,
   21↔22). The recent gate now also carries the magnitude channel, and at $1,168 it
   is large enough to tip a recent boundary trade (21↔22). This is the same
   PnL-magnitude source surfacing on a second gate, not a new channel — note it is
   *not* the V213 "sort merely moved the channel" failure mode (fsum is exact-rounded,
   not a re-sort), it is the magnitude channel becoming dominant once the entry
   channel that previously masked it is gone.

4. **`crisis_OFF` is hermetic** ($0.72 PASS, 30/30) — the crisis gate's trades sit
   far from any sizing/exit boundary the channel perturbs, so it stays clean. (Same
   pattern as crisis being the quietest determinism gate across V216–V219.)

**Net:** V220's specific bet (entry-flip → fsum → < $200) is REFUTED because it
aimed one layer too high. The fence is correct and load-bearing (entry count now
locked 26/26 on both trend arms — keep it), but determinism is **not** restored:
1/4 cells PASS (was 3/4 at V219). The eval surfaced a **sizing/exit PnL-magnitude
channel** that is invisible at the signal/entry layer (cycle-1 signal fingerprints
are clean post-V217-BLAS-pin; the divergence is downstream at the trade-PnL level).

This is the **fourth** order-channel this eval has peeled (V211 basket sums → V217
BLAS → V219/V220 sub-ulp entry-flip → V220 sizing/exit magnitude). Each fence
reveals the next layer; see `REFLECTION_V220.md`.
