## Hypothesis

The `strategy_selector_enabled` audit pre-registered in V211 cannot be run honestly because the `omega/nodes/victoria/strategy_selector.py` module **does not exist on `main`.** It was authored in the `claude/inspiring-edison-31c334` worktree (last touched commit `ae32019`, May 22 2026) but never merged. `strategy.py:656` reads:

```python
if getattr(self.features, "strategy_selector_enabled", False):
    try:
        from omega.nodes.victoria.strategy_selector import StrategySelector
        self._strategy_selector = StrategySelector(self.features)
        logger.info("V156 strategy_selector initialised")
    except Exception as _exc:
        logger.warning("V156 strategy_selector init failed: %s", _exc)
```

The `ImportError` is **silently caught** and `_strategy_selector` stays `None`. Worse: `strategy_selector_enabled` was never declared on the `VictoriaFeatures` dataclass on `main` — `getattr(..., default=False)` always returns `False`. So the inner `try` block has been unreachable on main for the entire V199–V211 arc. V204/V206b/V211-brief experiments that thought they were toggling the selector were honestly testing nothing.

**The V212 bet (restated honestly):** restoring the V196-era `strategy_selector.py` module (403 lines, stdlib-only imports) **plus** declaring `strategy_selector_enabled` and its 9 companion fields as real dataclass fields **plus** setting the flag True via `--features '{"strategy_selector_enabled": true}'` activates the V156/V157/V160/V161 regime-mode override system for the first time on main. Expected: some gate moves > 2σ (recent > $200, trend > $200, crisis > $28). If nothing moves, the entire V156-era subsystem was honestly inert.
