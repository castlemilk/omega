So the inner `try` block has been unreachable on main for the entire V199–V211 arc. V204/V206b/V211-brief experiments that thought they were toggling the selector were honestly testing nothing.

**The V212 bet (restated honestly):** restoring the V196-era `strategy_selector.py` module (403 lines, stdlib-only imports) **plus** declaring `strategy_selector_enabled` and its 9 companion fields as real dataclass fields **plus** setting the flag True via `--features '{"strategy_selector_enabled": true}'` activates the V156/V157/V160/V161 regime-mode override system for the first time on main. No high-water claim is possible; **README is not updated.**

**Mechanism — RESOLVED: within-process non-determinism (not cross-run contamination).** Initial confound: the non-determinism appears only on regime-switching gates (trend/crisis), not recent's stable-`normal` regime — but recent ran first (runs 1–4), trend/crisis later (runs 5–12), so "regime-switching triggers it" and "later-in-sequence accumulates state" were observationally identical in the audit.
