## Hypothesis

**Freeze every live `urllib` fetch in the Victoria signal layer during a frozen
backtest, and the determinism break collapses below the $200 fence.** V214 proved
the channel is input non-hermeticity: `OMEGA_FROZEN_CACHE` freezes `data_cache.py`
(FRED/funding/macro) but **not** the direct `urllib.request.urlopen` calls in
`signals_advanced.py` and ~25 sibling signal modules. Each replicate process is
fresh → fresh module cache → fetches **live** at its own startup wall-clock; at
sleep=10 the r1→r4 span (~2.5h) lets live data (and API up/down state) drift,
blowing the spread to $1,510. Block all outbound HTTP in frozen mode and every
signal degrades to its **deterministic fallback** (constant), so replicates become
byte-identical regardless of wall-clock separation.

This is the same class of fix as the WS-stub at `run_training.py:506` (backtest
mode disables live WS feeds); V215 extends the hermeticity guarantee from WS feeds
to HTTP fetches.

### Implementation approach (the value-choice, pre-registered)

Two mechanisms, mirroring the user-specified **A + C** bias:

**C — centralized HTTP guard (the determinism guarantee).** In `run_training.py`,
when `OMEGA_FROZEN_CACHE=1`, monkeypatch **`urllib.request.OpenerDirector.open`**
(NOT `urllib.request.urlopen`). Rationale: patching `urlopen` only catches callers
that invoke it as a module attribute; `signals/whale_flow.py` uses
`from urllib.request import urlopen` (bound at import → a `urlopen` patch silently
misses it). `OpenerDirector.open` is the **import-style-agnostic chokepoint** —
every `urlopen()`, however imported, routes through the global opener's `.open()`
at call time, so a class-method patch catches all of them. A repo sweep confirms
urllib is the **only** HTTP mechanism in the Victoria layer (no `requests`/`httpx`/
`aiohttp`), so this one patch is airtight. (Socket-level blocking was rejected — it
would kill the Postgres `DATABASE_URL` connection; `OpenerDirector.open` is the
correct altitude.) The guard:
- raises `urllib.error.URLError` on every call → caught by every signal module's
  broad `except Exception` → **deterministic fallback**, run completes;
- appends the URL to `data/{version}_http_during_backtest.jsonl` (loud, append-only);
- increments a counter surfaced in results `observability.http_blocked_count`.

**A — snapshot freeze (realistic values for the 2 localized signals).** Rather than
let `btc_dominance`/`long_short_ratio` degrade to the neutral 0.0 no-data fallback,
`signals_advanced.py` returns **snapshot-derived values** from a committed
`data/frozen_advanced_signals.json` when `OMEGA_FROZEN_CACHE=1`. The value choice
(pre-registered): **(b) snapshot-derived** — a one-time live capture committed to
the repo, NOT a neutral constant and NOT last-cached-pinned. This keeps the two
highest-signal feeders at a realistic recent level (e.g. dominance ≈ 0.58) so the
hermetic baseline stays close to live behaviour, while still being fully
deterministic. `vrp`/Deribit and all ~25 other modules are handled by C alone
(blocked → deterministic fallback) — chasing each one individually is whack-a-mole;
C neutralizes the whole class at one chokepoint.

**Why both:** C alone already guarantees determinism (block-all → constant
fallbacks). A only buys *realistic* values for the two signals V214 localized, so
the hermetic baseline isn't gratuitously far from live. With the guard raising on
**100% of network attempts**, any residual spread is **definitionally non-network**
— a strictly stronger discrimination than an empty-jsonl check.
