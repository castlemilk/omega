## Hypothesis

**Not a hypothesis about the strategy — a hypothesis about the eval.** The
recorded gate PnLs (V199 recent +$2,478, V201 trend +$12,996, etc.) are each
**one observation at one seed at one snapshot**. The reflection's trade-CSV
analysis showed 60–70% per-trade PnL drift on no-op code changes. If the
within-seed variance σ is comparable to the inter-version deltas we've been
chasing (typically $100–$2K), then several "high-water breaks" since V172 are
indistinguishable from noise.

V203 measures σ per gate so that future versions can require a 2σ delta before
claiming a high-water break.
