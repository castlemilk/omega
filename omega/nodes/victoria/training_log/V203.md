## Hypothesis

**Not a hypothesis about the strategy — a hypothesis about the eval.** The
recorded gate PnLs (V199 recent +$2,478, V201 trend +$12,996, etc.) are each
**one observation at one seed at one snapshot**. The reflection's trade-CSV
analysis showed 60–70% per-trade PnL drift on no-op code changes. If the
within-seed variance σ is comparable to the inter-version deltas we've been
chasing (typically $100–$2K), then several "high-water breaks" since V172 are
indistinguishable from noise.

V203 measures σ per gate so that future versions can require a 2σ delta before
claiming a high-water break.

## Conclusion

The eval has **three distinct noise regimes**, not one uniform noise floor.
This was not the going-in assumption — both REFLECTION_V202 and the
falsifier table treated noise as roughly comparable across gates. The
correct picture is:

- **σ_recent = $2,547** (2σ = $5,094). Catastrophically noisy. The
  V199 +$2,478 high-water that V200/V201/V202 spent three versions
  trying to beat or recover is **less than one σ from $0**. There is
  no recent high-water of record — the recorded number is one draw
  from a wide distribution centred near zero.
- **σ_crisis ≈ $0.5** (2σ = $1). Effectively deterministic.
  Identical 63 trades, identical loss to the dollar across all four
  seeds. Confirms REFLECTION §5: crisis is **not** a selection or
  sizing problem (those would respond to RNG), it is structural —
  exit-side, defensive-abstention, or direction-conditional. No
  amount of seed variation moves it because the regime detector +
  entry stack is locked into the same path regardless of RNG state.
- **σ_trend ≈ $1** (2σ = $2). Effectively deterministic too. V201
  on trend reads +$11,550 reproducibly. The logged V201 +$12,996 was
  $1,446 above this — that gap is **not** RNG noise (σ is $1), it
  is the seeded-vs-unseeded path difference (V201 ran without
  `--seed`; this run pins seed). Code state is identical (`1f53e77`).

- **V199 reproduction: REFUTED** (Δ = −$2,239, threshold was $50).
  But the right framing is not "V199 doesn't reproduce" — it is
  "the recent gate's σ is so large that single-seed numbers on this
  gate are not reliable observations." V199 at seed=42 reads +$239;
  another seed could read −$3,167 or +$3,058 with no code change.

- **Second crisis snapshot: built**, deferred to V204+.
