## §1 — Why this exists, and why it is not V280 again

V283 Phase 1 measured TimesFM as a materially better volatility forecaster than naive
(conditional ρ +0.39 vs +0.08, no memorisation signature). V283 Phase 0 then found it has
**no consumer**: the only volatility-driven decision in the strategy never executes, in
seven measured configurations.

So the missing thing is a *mechanism*, not a model. V283 §5 set three requirements:

| Requirement | How V284 meets it |
|---|---|
| a live consumer | per-ticker sizing multiplier applied every cycle, not a threshold that must be crossed |
| a **multiplicative** shape | `weights[t] *= mult[t]` after selection — it cannot dilute the composite, which is what V280 measured at −$1k–$3.2k/window |
| a distributional falsifier | §5 G3; sentinels are explicitly a diagnostic |

**This is deliberately the naive estimator, not TimesFM.** If the *mechanism* does not
pay with a cheap input, no model can rescue it — and if it does pay, swapping in
TimesFM's measured edge becomes a clean, isolated upgrade with its own Δ. Proving the
mechanism first is the whole lesson of V265 and V283.

## §2 — Phase 0 (the separator probe, run before this document)

The V234 standing rule: no build until the gate variable is shown to discriminate on the
binding windows. Rolling 20-bar vol per ticker, trim-only multiplier
`min(1, median_vol / current_vol)`:

| Window | multiplier min | mean | bars trimmed |
|---|---:|---:|---:|
| `snap_wf_20240310` (crisis) | 0.66 | 0.94 | 35 / 71 |
| `snap_wf_20230912` (trend) | 0.90 | 0.97 | 34 / 71 |
| `snap_wf_20250305` (recent) | 0.66 | 0.89 | 35 / 71 |

**It discriminates** — live on roughly half the bars, down to 0.66. This is the
qualitative difference from V283's dead gate: that used a single ticker's *basket-level*
rank against a fixed percentile and never crossed it; this is per-ticker and continuous.

## §3 — Mechanism (exact)

For each ticker `t` with a position:

```
vol_t      = stdev of the last `window` per-bar returns          (window = 20)
ref_t      = median of the rolling vol series over `lookback`    (lookback = 60)
mult_t     = clamp(ref_t / vol_t, floor, 1.0)                    (floor = 0.5)
weights[t] *= mult_t
```

**Trim-only by construction** (`≤ 1.0`). It de-risks a ticker whose current volatility is
above its own recent median and never up-sizes — matching the posture of every other
sizing overlay in this codebase (V241's reasoning layer `[0,1]`, V165's
`high_vol_size_mult ≤ 1`). Self-normalising per ticker, so no magic constant and no
cross-asset scale assumption.

## §5 — Gates

| Gate | Assertion |
|---|---|
| **G1** (unit, both directions) | `mult == 1.0` when current vol ≤ its median (no trim); `floor ≤ mult < 1.0` when vol is above median; never `> 1.0`; flag OFF ⇒ multiplier never applied. |
| **G2** (arm is live) | With the flag ON, the run logs the multiplier firing on a non-zero number of cycles. A $0.00 Δ from an arm that never fired is the V283 trap and must be excluded by evidence, not assumed. |
| **G3** (the measurement) | Paired per-window Δ, flag OFF vs ON, same host, N=2. **Sentinels are a diagnostic** — per V235 no claim about the standing baseline may rest on n=1 per family, so whatever the sign, the verdict is *"grid re-score required"*, never *"adopt"*. |
| **G-DET** | $0.00 spread, N=2, both arms. |

**Pre-committed reading of the outcomes:**

- **Δ ≈ 0 with G2 showing fires** ⇒ vol-target sizing is inert *in effect*; the lane
  closes and TimesFM's edge is confirmed to have nowhere to go.
- **Δ < 0** ⇒ refuted; flag stays OFF; **do not** then try TimesFM to rescue it, because
  a better input to a harmful mechanism is a worse mechanism.
- **Δ > 0** ⇒ the mechanism is a candidate. **Still not adopted here** — it earns a grid
  re-score, and only then does swapping in TimesFM become the next isolated experiment.

**Anti-Goodhart:** a positive three-window Δ is not a win. V231 refuted V227's shipped
+$630 the moment it was measured distributionally, and this version pre-commits to the
same treatment.
