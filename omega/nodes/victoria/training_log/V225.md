## Hypothesis

The existing basket (sma, rsi, macd, bb, zscore, volume, funding) is
momentum/mean-reversion — all long-biased and all *coincident-to-lagging* in a
crash (they flip bearish only *after* price has already broken). The crisis gate
is negative in every version because nothing in the basket *leads* a drawdown.

**Bet:** an **additive, one-sided risk-off term** that fires *before* the basket
catches up — derived from realized **downside-semivariance skew** + **drawdown
acceleration** over the replay window — improves the **crisis** gate by > $200
**without regressing trend or recent by > $200**. It is additive (composite +
skew·W), NOT an IC re-weight (IC is closed — V224). Because it is one-sided
negative ([−1, 0]) and ≈ 0 in benign tape, the no-harm constraint on trend/recent
is satisfied *by construction* — the signal barely exists outside crisis.

**Effect-magnitude prediction:** crisis Δ between +$200 and +$3,000 (enough to
move the gate but bounded by W=0.5); trend/recent Δ within ±$200 (skew ≈ 0 there).

**Decision (no user check, per the pre-committed "default to the deterministic

**realized downside-semivariance skew**, which IS a skew (of the return

## Signal definition (`omega/nodes/victoria/signals/crisis_skew.py`)

Per (cycle, ticker), from the replay `close` window (length = window, ≥ 2):

```
r_i        = ln(close[i] / close[i-1])           # i = 1 … n-1, fixed order
downside   = fsum(r_i^2 for r_i < 0)             # downside semivariance
upside     = fsum(r_i^2 for r_i > 0)             # upside semivariance
skew_raw   = (downside - upside) / (downside + upside)   # ∈ [-1, 1]; 0 if denom==0
semivar    = max(0.0, skew_raw)                  # one-sided ∈ [0, 1]

peak       = max(close)                          # exact (no FP sum)
dd_now     = close[-1]/peak - 1                  # current drawdown ≤ 0
dd_prev    = close[-2]/peak - 1
accel      = clamp(0, 1, (dd_prev - dd_now) / 0.05)   # drawdown deepening this bar

risk_off   = clamp(0, 1, fsum([0.65*semivar, 0.35*accel]))
raw_value  = -risk_off                           # ∈ [-1, 0]  (risk-off ⇒ NEGATIVE)
```

- **Sign convention:** downside-skew steepening / drawdown accelerating ⇒
  `raw_value → -1` (risk-off / bearish brake). Benign tape ⇒ `raw_value → 0`.
  One-sided: never bullish (the basket already supplies the long side).
- **Lookback:** the replay window (30 bars). No rolling z-score (that reintroduces
  the length/order-sensitive accumulator the V220/V221 fences closed); the ratio
  construction is intrinsically bounded.
- **Missing data → 0.0, never NaN:** `len<2`, `max==min`, `denom==0`, `peak<=0`,
  non-finite ⇒ 0.0. Component C (static funding) dropped from the first cut
  (inert in frozen mode; candidate V226 add).

## Integration as additive composite member (NOT IC re-weight)

`signal_generation.py`, after the composite is set (after line 1041), gated on
`crisis_skew_enabled`:

```
skew = self._crisis_skew.compute(prices)        # stored under ts["crisis_skew"] (non-_signal key)
if skew != 0.0 and "composite" in ts:
    ts["composite"] = max(-1.0, min(1.0, math.fsum([ts["composite"], _SKEW_W * skew])))
```

- `_SKEW_W = 0.5`. **Post-composite additive** — NOT routed through the basket

  it should bite). This is the faithful reading of "equal-weight basket **+ skew
  term**".

  incumbent. Default-False also dodges the V224 control trap (where a `{}` control
