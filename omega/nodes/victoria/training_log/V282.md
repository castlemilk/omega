### Mechanism

`omega/nodes/victoria/wasserstein_regime.py:38-44`:

```python
try:
    from scipy.stats import wasserstein_distance as _scipy_wasserstein
    _SCIPY_AVAILABLE = True
except ImportError:
    _SCIPY_AVAILABLE = False
    logger.warning("scipy not available — falling back to simple mean-distance approximation")
```

`WassersteinRegimeDetector` is the registered `"regime"` detector
(`omega/core/project_config.py:330`). Without scipy it silently swaps **true Wasserstein
distance for a mean-distance approximation** — a *different algorithm*, not a numerical
wobble — which changes regime distances → regime labels → the regime-adaptive conviction
thresholds → the trades taken.

**`scipy` is declared nowhere in `pyproject.toml`** — not in `dependencies`, not in the
`math` / `telemetry` / `dev` extras. The campaign's entire measuring stick has depended,
for its whole life, on a package the project does not declare and whose absence
downgrades an algorithm with a `logger.warning`.

## §2 — What this settles

- **R5 is closed.** The standing baseline **does** reproduce off-host — it always did,
  given the right environment. V276's G2, which failed as written, would now pass.
- **The V276/V277/V282-Phase0 "code environment is unpinned" thesis is confirmed with a
  concrete instance**, not merely argued.
- **It vindicates the discipline that caught it.** V276 ran a paired control purely to
  attribute a delta. Without it, a −$67 crisis move would have been read as V276's own
  regression, and the real cause — an undeclared dependency silently changing a regime
  algorithm — would have been attributed to a flag flip.

## §3 — Hypothesis

> A missing dependency that silently changes an algorithm is a **substrate defect**, and
> the V219 manifest philosophy already has the right answer for substrate defects:
> **refuse to produce a baseline on it.** Declaring `scipy` fixes today's instance;
> making its absence *loud* fixes the class.

**Falsifier:** if declaring scipy and hardening the import changes any sentinel by a
cent, the fix has side effects — **STOP**.

## §7 — Conclusion

**R5 is closed, and the answer was a package nobody had declared.**

The chain: `scipy` absent → `wasserstein_regime.py` silently substitutes mean-distance
for true Wasserstein → regime distances change → regime labels change → the
regime-adaptive conviction thresholds change → different trades → crisis −$66.96,
recent +$52.83. Trend was unaffected throughout, which is why the deviation looked like
noise rather than a mechanism.

**What made this findable was refusing to round anything up.** V276 could have shipped
with G2 marked pass — its own change was provably $0.00 — and the deviation would have
been filed as "off-host noise". Instead the bar was left FAILED as written, the paired
control was run to attribute it, V277's Phase 0 eliminated four hypotheses and left the
fifth **explicitly untested rather than assumed benign**, and V282 tested it the moment
the network allowed. Four versions, no guessing.

**The general lesson, and it is not about scipy.** A dependency that *degrades an
algorithm* on ImportError is far more dangerous than one that fails outright: a hard
failure is a bug report, a soft fallback is a silently different measuring stick. The
codebase has more of these — the same run logs `hmmlearn not available — using numpy GMM
fallback`, and V279 catalogued five other inertness classes. Every one is a candidate for
the same defect.

**Standing baseline: UNCHANGED and NOT edited** — it was never wrong. It was
*unverified off-host*, which V276 §6 was careful to distinguish, and it is now verified.
