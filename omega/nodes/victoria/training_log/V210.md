## Localization: first divergent computation

`composite_score` in `metrics.jsonl` is set after per-symbol composite formation and basket-level rescaling. Code paths that aggregate per-symbol composites with dict iteration order, in HEAD:

1. **`strategy.py:1722–1735` — basket_std**:
   ```python
   _composites_for_std = [
       float(sig["composite"])
       for t, sig in signals.items()       # <- unsorted dict iteration
       if not t.startswith("_") and not t.startswith("adv_")
       and isinstance(sig, dict) and "composite" in sig
   ]
   if len(_composites_for_std) >= 2:
       _c_mean = sum(_composites_for_std) / len(_composites_for_std)
       _basket_std = math.sqrt(
           sum((v - _c_mean) ** 2 for v in _composites_for_std) / len(_composites_for_std)
       )
   ```
   Floating-point `sum` is **order-dependent** at the 1e-15 level per addend; with ~10 symbols and composites ~0.05 in magnitude, accumulated error is ~1e-15 × 10 = 1e-14 → negligible by itself. But `_basket_std` feeds `_thresh_scale = min(_basket_std / 0.20, 1.5)` which multiplies every per-symbol composite's downstream threshold and `_cs_norm = 0.20 / (0.3 * _basket_std)` which rescales every per-symbol composite. Small `_basket_std` drift propagates multiplicatively into every per-symbol conviction calc.

2. **`strategy.py:2130–2138` — basket_mean**:
   ```python
   _basket_composites = [
       float(sig["composite"])
       for t, sig in signals.items()       # <- unsorted dict iteration
       if not t.startswith("_") and not t.startswith("adv_")
       and isinstance(sig, dict) and "composite" in sig
   ]
   _basket_mean = (
       sum(_basket_composites) / len(_basket_composites) if _basket_composites else 0.0
   )
   _suppress_longs_basket = _basket_mean < -0.10
   ```
   Same construction, same order-sensitivity. `_basket_mean` feeds the `_suppress_longs_basket` gate (cycle-level long suppression) and is subtracted from per-symbol composites (the "demeaning" step that produces `demeaned_composite` in signal_contribs).

3. **Per-symbol composite formation upstream** — `_compute_weighted_conviction` at strategy.py:1024 traverses `signals_dict` for weight calculation; signal-name keys would have to be iteration-ordered. We have to instrument to confirm whether this is the loop that produces the 1e-4 per-symbol drift OR whether it's downstream demeaning. **Both paths are unsorted in HEAD.**

Crisis's 100× bigger cycle-1 composite drift (1e-2 vs 1e-4) is consistent with crisis snapshot having larger absolute per-symbol composites (negative magnitudes near 0.3+) — same relative iteration-order error, larger absolute drift. The crisis short-bias short-conviction threshold of 0.05 sits ~6× the drift magnitude; recent's normal-regime short threshold of 0.05 with composites near −0.03 sits ~2× drift magnitude → one-trade-cycle-184 bifurcation.

## Why crisis is robust but recent/trend aren't (the asymmetry, structurally)

| Aspect | Crisis | Recent / Trend |
|---|---|---|
| Cycle-1 composite drift | **1e-2** (100× larger) | **1e-4** |
| Selection bifurcations | **0/65** | recent: 3/71 (cycle 184); trend: 9/91 (cycle 38) |
| Conviction threshold structure | Long suppressed (0.20), short permissive (0.05) — strong directional commitment | Normal: long 0.10 / short 0.05. Trend: similar but with cycle-26 vol-regime changes |
| Drift / threshold ratio | drift 1e-2 ≪ short threshold 0.05 → decision-stable | drift 1e-4, but candidates *sit at* 0.04-0.06 — one-flip bifurcations |
| Result | Exit-side $28 σ only | Selection-side $1,500–$2,700 σ |

Crisis sizing/selection has **built-in robustness from the strong-directional regime structure**, not from any V207–V208 fix. The fixes shrank crisis from $1,978 → $113 → $56 by killing absolute-drift channels, but the headroom-to-threshold was always large. Recent and trend will not benefit from the same fixes proportionally; they need the upstream composite-formation channel closed AND/OR explicit marginal-candidate hysteresis.
