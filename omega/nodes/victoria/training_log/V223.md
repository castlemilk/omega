## Hypothesis

V222 proved IC weighting is cleanly regime-conditional (both Δs common-mode —
the `_ic_weighted_composite` fsum fence cancels). The highest-EV, smallest-
surface next bet **banks the trend gain and removes the crisis loss**: gate the
IC-weighted conviction path on the cycle's **runtime regime label**. Apply seed
IC weights only where IC helps; fall back to the exact equal-weight raw
composite (bit-identical to the V222 IC-off control path) where it hurts.

**Bet:** regime conditioning preserves the trend IC gain while recovering the
crisis and recent losses, because recent's profit windfall lives in crisis
sub-cycles that will now bypass IC and re-capture the equal-weight selection.

## RESOLVED FORK — denylist on {crisis, high_vol}, NOT allowlist {trend,bull,normal}

The V223 brief said "use IC only in **trend/bull/normal**, bypass in
**crisis/high_vol**." The Explore + Plan agents refuted the *allowlist* wording
against the actual runtime label space:

- **`_cycle_regime_label` (strategy.py:1132,1136)** is `str(signals["_regime"]).lower()`.
  Its closed value set is **`{bull, bear, sideways, high_vol, crisis, default}`**
  (Wasserstein emits bull/bear/sideways `wasserstein_regime.py:66-70`; VRP maps
  FEAR→high_vol, COMPLACENCY→crisis `victoria_node.py:120-124`; macro forces
  sideways `:1299`; fallback `default` `:931`).
- **There is NO `trend` runtime label** — "trend"/"recent"/"crisis" in the
  results are **training SNAPSHOT names** (data periods), a different namespace.
- **`normal` is never directly emitted** — the code conflates it with `sideways`
  (`strategy.py:1769 _is_normal = _regime_consolidated in ("normal","sideways")`).
- The per-regime IC table (`data/signal_ic_history.json → seeded_regime_ics`) is
  keyed on exactly **`normal` / `crisis` / `high_vol`** — no `trend`/`bull` keys.

An **allowlist** of `{trend, bull, normal}` would bypass IC for every
`sideways` / `bear` / `default` / `unknown` cycle — i.e. the bulk of
trend-snapshot trading — silently discarding V222's proven +$3,331 trend gain.
**The faithful implementation of the brief's intent ("IC-off in crisis/high_vol")
is a denylist:**

- **IC-OFF (bypass → equal-weight raw composite):** `crisis`, `high_vol`
- **IC-ON (use IC weights):** everything else — `normal`, `sideways`, `bull`,
  `bear`, `default`, `unknown`, `""`.

Gate keys on the **runtime `_regime` label**, never the snapshot name.
