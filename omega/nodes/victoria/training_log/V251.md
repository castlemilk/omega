## Design — why the reconciliation reduces to an OHLCV input diff

The standing-baseline eval consumes exactly two inputs from a walk-forward
snapshot: (a) per-symbol OHLCV arrays, (b) the `_macro` block. The V240-selective
baseline runs `frozen_series_enabled=OFF`, so the macro *series* feeds
(VIX/DXY/yield/GDELT/funding-series) are NOT consumed — only OHLCV + the `_macro`
block drive decisions. Per §6 the reconciliation **holds macro (incl. funding) at
its frozen value**, so the ONLY live-vs-frozen variable is the OHLCV feed —
precisely what V250's live pollers replace.

Two arms, **one** eval code path (`run_training.py --backtest-snapshot`):
- **Arm A (backtest):** the committed frozen snapshot.
- **Arm B (live-replay):** a snapshot rebuilt with OHLCV fetched **live** from
  Binance klines (every fetch through `omega.live_paper.feeds.assert_live_source`
  → exercises the frozen-path guard, C4), macro copied verbatim from frozen (§6).

Because the eval is **hermetic** (byte-identical output from byte-identical input —
the property the V214→V221 determinism arc established and re-proved
distributionally), if Arm B's OHLCV equals Arm A's OHLCV bar-for-bar, the eval
output is identical → per-regime PnL Δ = **$0** < 2·SE trivially. So the gate is a
two-layer proof:
- **Layer 1** — OHLCV input diff across all 32 windows (`v251_reconcile.py`).
- **Layer 2** — empirical output-equivalence on the 3 sentinels (`v251_layer2.sh`),
  running the real strategy+engine to CONFIRM input-identity ⇒ output-identity on
  this exact code+config (not just assert the hermetic property).

Config for both arms = the standing **SELECTIVE** baseline (V227 skew ON +
regime-gate + X=0.12; `universe_selective_enabled`; IC/brake/predemean/throttle
OFF). **All V241–V248 flags OFF; V243-A blacklist-ext OFF** (cleanest baseline).
Cell-identity asserted per run (`assert_cell_identity.py`: skew=on, gate=on,
ic=off — matches the baseline).
