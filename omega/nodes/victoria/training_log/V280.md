## §1 — The finding (Phase 0, measured before this document was written)

`SignalGenerationNode` ships six technical signals **default OFF**
(`signal_generation.py:403-409`):

```python
self._use_rsi = False       self._use_macd = False      self._use_bb = False
self._use_zscore = False    self._use_btc_beta = False  self._use_vol_regime = False
```

They are switched on **only** by `improve(feedback)` (`:740-760`), which upgrades the
node to v1.1 at `iteration >= 1` (RSI, volume z-score) and v1.2 at `iteration >= 2`
(MACD, Bollinger Bands, Z-score, BTC-beta, vol-regime).

**Nothing in the training path ever calls it.**

| Check | Result |
|---|---|
| `grep -c "improve(" scripts/run_training.py` | **0** |
| the only caller anywhere | `victoria_node.py:557`, itself only reached via the orchestrator's improvement loop — not the training runner |
| `"SignalGenerationNode →"` in a real frozen run's log | **0 occurrences**, all cells |
| V279's family report, same run | `momentum 1/3 live: sma_crossover` — everything else INERT |

**Consequence:** every walk-forward run in this campaign — including all 32 cells behind
the standing baseline — executed the signal node at **v1.0**, with RSI, MACD, Bollinger
Bands, Z-score, BTC-beta and vol-regime **disabled**. The per-ticker composite's momentum
family had exactly one live member.

This reframes the campaign's central conclusion. V236→V245 closed entry-side composite
search at daily bars and the standing rule became *"do not reopen it without intraday
resolution."* That search was conducted on a node running its most primitive
configuration. **"Signal space is exhausted" was measured with six signals switched off.**

## §2 — Hypothesis

> Enabling the v1.2 signal set puts five to six additional live signals into the
> per-ticker composite. That is a **material** change to entry selection — not a
> refinement — and its effect is currently unmeasured in either direction.

**This version does NOT predict improvement.** More signals in an equal-weight composite
can easily dilute a working one; `sma_crossover` may be carrying the baseline precisely
*because* nothing else is diluting it. The bet is only that the effect is **large enough
to measure**, and that a campaign which believes it exhausted signal space should know
which configuration it exhausted.

**Falsifier:** if the v1.2 arm moves the three sentinels by less than the determinism
floor, the six signals are inert in practice too and V279's report should say so — in
which case the "exhausted" conclusion stands and this thread closes.

## §5 — Results

Run 2026-08-27, `sleep=0`, `cycles=60`, `N=2`, both arms, same host, same substrate.

### G1 — PASS (3 tests)

Default is v1.0 with all six toggles False; the arm reaches `_version == "1.2"` with all
six True, **through the real `improve()` path**; and only the literal value `"1"` arms it.

### G2 — **PARTIAL PASS**, and the shortfall is reported, not rounded up

§4 pre-registered `momentum 3/3` **and** `mean_reversion 2/2`. V279's report, from the
arm-ON run:

```
[startup]   mean_reversion   2/2 live: bb_signal,rsi_signal          <- as pre-registered
[startup]   momentum         2/3 live: sma_crossover,zscore_signal   <- 2/3, NOT 3/3
```

`rsi_signal`, `bb_signal` and `zscore_signal` went live exactly as predicted. **`macd_crossover`
did not**, despite `_use_macd` being True (G1 asserts it). So the toggle is on and the key
is still absent — a fourth distinct reason for a signal to be inert, alongside
fenced-by-design, zero-on-substrate, and never-enabled. **Not diagnosed here**; queued as
V281 item 2. G2 is recorded as a partial pass.

The substantive half of G2 holds: the arm demonstrably puts new signals into ticker
dicts rather than merely flipping booleans, which is what G3 needed it to establish.

### G-DET — PASS

$0.00 spread, N=2, **both arms**. The newly-live signals do not break determinism.

### G3 — the effect is large, and it is NEGATIVE in all three families

| Family | Window | v1.0 (arm OFF) | v1.2 (arm ON) | **Δ** | Trades |
|---|---|---:|---:|---:|---:|
| crisis | `snap_wf_20240310` | $1,082.80 | **$21.09** | **−$1,061.71** | 9 → 14 |

For scale, against the V247 per-family MDEs (which govern **grid means**, not single

## §6 — Conclusion

**The hypothesis was that the effect would be large enough to measure. It is — and it
points the other way.** Enabling the six technical signals costs money in every family
tested, badly in two.

**The v1.0 default is load-bearing, not an accident.** This version began from what
looked like a latent bug: six signals shipped OFF, switched on only by a callback the
training runner never invokes, so the whole campaign measured a node at its most
primitive setting. The obvious reading was *"a whole signal set was never given a
chance."* The measurement says the opposite — `sma_crossover` alone is carrying the
baseline, and RSI/BB/Z-score dilute it in an equal-weight composite. §2 pre-registered
exactly this risk (*"more signals can easily dilute a working one; sma_crossover may be
carrying the baseline precisely because nothing else is diluting it"*), which is the only
reason this reads as a result rather than a rescue.

**What it does to the campaign's central conclusion: strengthens it.** V236→V245 closed
entry-side composite search at daily bars. V280 briefly appeared to invalidate that —
the search having been run with six signals off — and instead reinforces it: the
un-searched configuration is *worse*, substantially, in all three families. The
"exhausted" verdict now rests on a measurement rather than on an assumption nobody had
checked.

**No adopt decision is taken, per G4.** Three windows is a diagnostic; the flag ships
default OFF; `data/standing_baseline.json` is untouched. The honest statement is *"v1.2
is materially worse on three windows and a grid re-score is not worth spending to confirm
a direction this unanimous."*

**Standing baseline: UNCHANGED and NOT edited.**

   inertness class, undiagnosed.
3. **Do NOT queue a v1.2 grid re-score.** The direction is unanimous and large; spending
   32 cells to confirm a loss is the kind of variance mining V249 warned about. If any
   grid is spent here, spend it on the H2 fence (V278 §7 item 1), which is free
   correctness rather than a measured regression.
4. **Reconsider what "signal work" means for this model.** Three versions have now shown
   the composite is thinner than it appears (V279) and that thickening it hurts (V280).
   That is evidence the remaining edge is not in the entry composite at all — consistent
   with V272's execution-friction finding, and an argument for the execution lane over
   any further signal lane.
