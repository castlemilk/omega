## Hypothesis

**V227 already solved the exact analogous problem for the crisis-skew**: it
replaced a categorical `{crisis,high_vol}` regime gate with a *per-ticker realized
drawdown magnitude* discriminator (`_realized_drawdown_mag`, last `_DD_LOOKBACK=5`
daily bars, `1 − close[-1]/max(close[-5:])`), firing only when drawdown > X=0.12.
That turned an indiscriminate label into a real crash selector (crisis +$630).

**V229 = drawdown-gate the IC overlay the SAME way.** Replace the categorical
`{crisis,high_vol}` IC bypass with a per-ticker realized-drawdown discriminator:
**bypass IC to equal-weight when `_realized_drawdown_mag > ic_drawdown_threshold`,
regardless of the categorical label.** So IC turns off on genuine-drawdown cycles
even when labeled normal — exactly the 121 normal-labeled crisis-window cycles
where IC currently does its damage.

The IC gate is *additive* to the existing V223 categorical bypass (it fires on
cycles the label misses), not a replacement — the V223 branch still short-circuits
crisis/high_vol-labeled cycles first; the new branch catches the normal-labeled
high-drawdown remainder. Reuses V227's `_realized_drawdown_mag` helper verbatim
(already fsum-safe: a `max` + one divide, no accumulation).

### Why per-ticker granularity aligns

`_compute_weighted_conviction` runs once per ticker, and `_realized_drawdown_mag`
is per-ticker — so per-ticker IC conviction and per-ticker drawdown align 1:1. The
per-ticker dd-mag is already stashed as `ts["_skew_dd_mag"]` in
`signal_generation.py` (V227), so no new computation is threaded — V229 hoists that
stash to be unconditional (currently only set inside the `crisis_skew_enabled`
block) so the IC gate reads it whether or not the skew feature is on.

## Predicted `ic_skip` distribution at X=0.12

Using V227's per-ticker drawdown calibration (cycles with max drawdown ≥ 0.12:
**trend 15, recent 21, crisis 31**), the IC drawdown gate newly bypasses the
**normal-labeled** subset of those (cycles the V223 categorical bypass misses):

- **trend:** ~≤15 ticker-cycles bypassed. The +$875 trend edge comes overwhelmingly
  from benign no-drawdown cycles → trend should hold near +$875 (small give-back).
  **This is the key non-regression to watch.**
- **recent:** ~21 ticker-cycles bypassed (recent's edge historically lived in a
  crisis sub-window → directionally protective).
- **crisis:** ~31 ticker-cycles bypassed — the load-bearing number. The 121
  normal-labeled crisis cycles that carry the −$2,808 IC loss are precisely the
  genuine-drawdown cycles; bypassing the high-magnitude tail strips IC concentration
  off the cycles multiplied by the largest adverse moves (the same mechanism that
  moved crisis +$630 for the skew at identical X=0.12). Recovery to above −$200
  requires the gated cycles to carry ≳$2,600 of the loss — plausible if the loss is
  tail-concentrated (typical crisis PnL), not guaranteed. **Fallback (fork #3):**
  sweep X downward (0.10, 0.08) to capture more of the 121 normal-labeled cycles.
