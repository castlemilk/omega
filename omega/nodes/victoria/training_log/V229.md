## Hypothesis

**V227 already solved the exact analogous problem for the crisis-skew**: it
replaced a categorical `{crisis,high_vol}` regime gate with a *per-ticker realized
drawdown magnitude* discriminator (`_realized_drawdown_mag`, last `_DD_LOOKBACK=5`
daily bars, `1 − close[-1]/max(close[-5:])`), firing only when drawdown > X=0.12.
That turned an indiscriminate label into a real crash selector (crisis +$630).

**V229 = drawdown-gate the IC overlay the SAME way.** Replace the categorical
`{crisis,high_vol}` IC bypass with a per-ticker realized-drawdown discriminator:
**bypass IC to equal-weight when `_realized_drawdown_mag > ic_drawdown_threshold`,
regardless of the categorical label.** So IC turns off on genuine-drawdown cycles
even when labeled normal — exactly the 121 normal-labeled crisis-window cycles
where IC currently does its damage.

The IC gate is *additive* to the existing V223 categorical bypass (it fires on
cycles the label misses), not a replacement — the V223 branch still short-circuits
crisis/high_vol-labeled cycles first; the new branch catches the normal-labeled
high-drawdown remainder. Reuses V227's `_realized_drawdown_mag` helper verbatim
(already fsum-safe: a `max` + one divide, no accumulation).

### Why per-ticker granularity aligns

`_compute_weighted_conviction` runs once per ticker, and `_realized_drawdown_mag`
is per-ticker — so per-ticker IC conviction and per-ticker drawdown align 1:1. The
per-ticker dd-mag is already stashed as `ts["_skew_dd_mag"]` in
`signal_generation.py` (V227), so no new computation is threaded — V229 hoists that
stash to be unconditional (currently only set inside the `crisis_skew_enabled`
block) so the IC gate reads it whether or not the skew feature is on.

## Conclusion

- **Fork #1 (SHIP) REFUTED, and fork #3's remedy (calibrate X) is EXHAUSTED.** The
  drawdown gate does not make IC crisis-safe at the V227-validated X=0.12 (crisis Δ
  −$2,009), and the pre-registered X-sweep shows **no X jointly recovers crisis and
  preserves trend** — crisis floors at −$1,559 (X=0.05) while trend stays +$1,600 to
  +$3,000. The prediction "X→0 ⇒ crisis → skew-only −$2,991 (Δ +630)" was **wrong**:
  per-ticker IC↔equal-weight mixing *within a cycle* changes basket SELECTION, and the
  hybrid is non-monotonic and sometimes catastrophic (X=0.08 crisis −$8,999), not a
  clean fade to the IC-off number.
- **Mechanism (the real V229 finding): the crisis IC harm is structural/distributed,
  NOT drawdown-tail-localized.** V224 already named the harm as "conviction
  concentration on the 121 normal-labeled crisis cycles"; V229 adds that it is **not
  concentrated on the deep-drawdown subset** of those cycles — gating by realized
  drawdown (the discriminator that fixed the *skew* in V227) does not transfer to IC,
  because the skew is an *additive directional brake* (a magnitude gate suppresses it
  cleanly) whereas IC is a *cross-signal re-weighting of selection* (gating it
  per-ticker churns the basket).
- **Operative outcome = fork #2's ACTION** (pivot to a third orthogonal crisis-safe
  signal class), reached by a different path than fork #2's literal condition: trend
  did NOT collapse (it improved). **IC is now structurally crisis-incompatible across
  five refutations** — V222 (always-on), V223 (categorical-gated), V224 (empirical
  OOS), V228 (stacked), V229 (drawdown-gated). The crisis-IC-overlay program is closed.
- **Bonus, banked (trend-only): the drawdown gate is a BETTER trend lever than plain
  IC.** Drawdown-gated IC gives trend **+$1,428 hermetic (N=2, X=0.12)** vs the banked
  V224 IC-only **+$875** and the equal-weight main **−$218** — and up to **+$2,786**
  (N=1, X=0.08). It is **NOT promotable to main** (loses crisis −$2,009 and recent
  −$212 at X=0.12), so it joins the trend-only overlay backlog, superseding the V224
  IC as the strongest parked trend lever. The standing main is **unchanged from V227**
  (drawdown-gated crisis-skew; flags `ic_drawdown_gate_enabled` default OFF).
- **No high-water broken on main.** crisis stays V227 −$2,991.17; recent stays
