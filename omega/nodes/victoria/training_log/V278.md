## §2 — Hypothesis

> `dxy_signal` and `yield_curve` consume macro data from the replayed bar's future in
> every frozen run. Fencing them under `OMEGA_FROZEN_CACHE` — **exactly as `vix_signal`
> and `spy_signal` already are** — makes the frozen path causally honest.

V240.B measured both as **near-inert** contributors, so the *predicted* effect is small.
That prediction is the thing being tested, not a reason to skip the test: V273's own
wording is that four years of lookahead *"were structurally available and measured to
contribute little, which is a finding about effect size, not about correctness."*

**Falsifier:** if fencing moves any family beyond the determinism floor, the standing
baseline is contaminated by macro lookahead and must be re-derived on the full grid.
That is a finding, and it **stops** here — V278 will not attempt the re-derivation.

## §5 — Results

Run 2026-08-27, `sleep=0`, `cycles=60`, `N=2`, both arms, same host, same substrate.

### Deviation from §3, recorded not hidden

§3 item 1 pre-registered the arm as a `features.py` flag. **It shipped as an environment
variable instead** (`OMEGA_MACRO_BAR_FENCE=1`, active only when `OMEGA_FROZEN_CACHE=1`).
Reason: `DXYSignal.__init__(window)` and `YieldCurveSignal.__init__()` take **no features
object**, and `signal_generation.py:459/471` construct them without one — so a
`VictoriaFeatures` flag cannot reach them without threading a new parameter through the
signal layer, which is a larger change than this measurement warrants. The existing
precedent for exactly this fence (`vix_signal.py:106`, `spy_signal.py:116`) is
environment-based. `features.py` was therefore **not touched**; the change surface is 3
files, not 4.

### G1 — PASS (the arm is real, and off by default)

`tests/test_macro_fence.py`, 3 tests. The load-bearing assertion is
`fake_cache.get_values.assert_not_called()` under the arm: the fence does not merely
change a return value, it **closes the read path**. Also pinned: the fence stays inert
unless *both* env vars are set, so arm-OFF is byte-identical to pre-V278 and the live
path is untouched.

### G-DET — PASS

$0.00 spread, N=2, **both arms**, all three windows.

### Why that $0.00 is NOT evidence that H2 is harmless

Reporting the Δ alone would be the "gate that cannot fail" mistake this campaign has
made before, so the arm was interrogated directly rather than inferred from PnL.

**1. The leak is confirmed REAL at the data layer.** Replaying a 2024-03 window, with
`OMEGA_FROZEN_CACHE=1`, `YieldCurveSignal` reads:

```
ARM OFF   yield_curve=+0.000000  mode=neutral  10y=4.53  2y=3.84
ARM ON    yield_curve=+0.000000  mode=stub     10y=0.00  2y=0.00
```

`10y=4.53 / 2y=3.84` are **2026 rates** (the cache's own newest rows). H2 is not
theoretical: future macro data reaches the signal object. The fence closes it.

**2. The signal's OUTPUT is 0.0 anyway — for a contingent reason, not a structural one.**
The spread is `(4.53 − 3.84) × 100 = +68.8 bp`, an ordinary upward-sloping curve, which
maps to the `neutral` band ⇒ `0.0`. **This is a property of what the committed cache
happens to contain, not of the design.** A cache holding an inverted curve would inject
a non-zero constant drawn from the replayed bar's future, and the Δ would not be $0.00.
The correct statement is *"inert at this cache's contents"*, never *"inert"*.

**3. These cells may not exercise the signals at all.** Every trade's `signal_traces` in
all three windows contains exactly one name — `sma_crossover`. `dxy` and `yield_curve`
appear **nowhere** in any `signal_contribs.jsonl`. Both are commented "market-level,
applied to all tickers", and a market-level constant is removed by the cross-sectional
demean regardless of its value. So on these windows the fence had two independent
reasons to measure $0.00, and this probe cannot separate them.

**4. Probe caveat on `dxy`.** The direct measurement above fed a synthetic monotonic
BTC series, so its `dxy=0.000000` reflects a degenerate correlation input, **not** a
finding about `dxy` in a real run. `DTWEXBGS` returns 21 values against `window=20`, so
`dxy` is *able* to emit a non-zero signal. Its real-run value is unmeasured. Only the
`yield_curve` reading above is substantive.

Three windows is a **diagnostic, not an acceptance unit**. Per the V235 walk-forward rule

## §6 — Conclusion

**H2 is CONFIRMED REAL and MEASURED INERT on three windows — and those two statements
are both necessary.** Future macro data (2026 rates, replaying 2024) demonstrably reaches
`YieldCurveSignal` in the standing frozen configuration. Fencing it costs **$0.00** on all
three sentinels at $0.00 determinism.

The inertness is **contingent, not structural**: it holds because 2026's yield curve is
un-inverted and lands in the neutral band, and because these cells' composites contain
only `sma_crossover`. Neither is a property anyone designed or verified, and neither is
stable — a different committed macro cache, or a configuration in which the market-level
signals survive the demean, changes the answer with no code change at all. V273's
formulation was *"a finding about effect size, not about correctness"*; V278 sharpens it
to **a finding about effect size at one cache's contents**.

**The actionable asymmetry:** the fence costs $0.00 and removes a genuine lookahead. That
is a correctness improvement at measured zero cost — rare, and worth taking. V278 does
**not** take it: the flag ships default OFF as pre-registered, because adopting a default
change on the strength of three windows is exactly the inversion of the V235 rule, and
because V276 §6 R5 means this host's numbers are not yet trusted against the committed
baseline. The adopt decision belongs to a grid re-score.

**Standing baseline: UNCHANGED and NOT edited.** No performance claim; every gate here is
a control or a reproduction.

**Bearing on the objective (a paper-validated forward edge):** H2 does not appear to be
inflating the standing baseline on these windows, which is mildly good news for the
backtest. It does not move the forward picture at all — the V272 refutation of
funding-carry's live-deployability and the −$921 independent-window recent regime are
untouched by anything here.
