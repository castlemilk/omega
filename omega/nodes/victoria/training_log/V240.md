## Model choice (2026-07-11 discovery — supersedes "Kimi v2.7" below)

The user chose against Kimi. Discovery of what is actually usable:

- `DEEPSEEK_API_KEY`: **absent** everywhere (harness/.env, omega/.env, ~/.env).
- `OPENROUTER_API_KEY` (omega/.env): present but **dead** — 401 "User not
  found" on `GET /api/v1/key`.
- `GOOGLE_API_KEY` / `GEMINI_API_KEY`: **empty**.
- `GLM_API_KEY` (harness/.env): populated; endpoint authenticates but is not
  one of the two pre-approved options — noted as fallback only.
- **`agy` CLI (v1.0.16, `~/.local/bin/agy`): WORKS headless**
  (`agy -p "<prompt>"`), authed, backed by **Gemini 3.1 Pro**; `--model` can
  pin `Gemini 3.1 Pro (Low/High)` / `Gemini 3.5 Flash (…)`.

**Choice: Gemini via `agy` subprocess** (the only available pre-approved
option). Consequences for the design below:

- The CLI exposes no `temperature`/`top_p` control ⇒ **live-call determinism
  is NOT assumed.** Determinism is guaranteed entirely by the frozen cache:
  cache-fill runs pay one live call per unique prompt hash; replay under
  `OMEGA_FROZEN_CACHE=1` reads committed JSON only and raises `LLMCacheMiss`
  on any miss. The smoke's determinism claim is therefore about the
  cache/replay path, plus a measured (not assumed) repeat-sampling agreement
  check at cache-fill time.
- `model_id` recorded in the cache manifest = the agy model string
  (`gemini-3.1-pro-low`), best-effort — agy does not return a served-model
  fingerprint, so the manifest records the CLI version + model string instead.
- Cost: agy usage is subscription-side (no per-token bill for the smoke).

# V240.D (historical pre-reg) — Kimi reasoning layer: hermetic per-cycle basket review (scaffolding + smoke)

**Date pre-registered:** 2026-07-10 · **Author:** claude (Opus 4.8)
**Parent:** V239 (universe/blacklist flip — must land + universe stable first)
**Status:** pre-registered scaffolding. **Do NOT launch until V239 lands and the
universe is stable.** This version builds the reasoning-layer plumbing and runs
a single-window cache-fill smoke only; the falsifier eval is **V241**.

Supersedes the "corr-spike portfolio tail cap" that `V239.md`'s queue named as
the V240 candidate — the tail cap is re-slotted to **V242+** (its offline
PCA/copula calibration is $0 and may still run anytime; execution spec remains
`V237.md`'s historical section).

## Hypothesis (one sentence)

A frontier reasoning model given the full per-cycle portfolio view — regime,
sentiment/macro state (the V238 series), the complete candidate list with signal
breakdowns, recent basket PnL/drawdown, and the outcomes of similar past
decisions — can veto or re-weight the quant book's basket in a way that adds
recent expectancy without degrading trend/crisis; V240 only builds the hermetic
plumbing and proves determinism, V241 measures whether it does.

## Design (finalized in Dispatch)

- **Model:** Kimi **v2.7** via Moonshot AI (OpenAI-compatible API). Reuse the
  existing `OpenAICompatibleProvider` in `omega/nodes/victoria/signals/llm_analyst.py`
  (V139) — endpoint `https://api.moonshot.cn/v1` (intl: `https://api.moonshot.ai/v1`),
  key from env `KIMI_API_KEY`. Cost table entry already present
  (`kimi-v2`/`kimi-v2-5` = $0.15/M in, $0.60/M out); add `kimi-v2-7` when the
  price is confirmed.
- **Determinism:** `temperature=0`, `top_p=0.01`, model **version pinned** in the
  cache manifest (exact served model id recorded alongside each cache entry;
  a served-id mismatch on replay is a hard error, not a silent accept).
- **Cache pattern (hermetic, mirrors V215/V238):**
  `data/frozen_llm_cache/{model_id}/{prompt_hash}.json` where `prompt_hash =
  sha256(canonical_prompt_json)[:16]`. This is a **separate** store from the live
  `data/cache/llm_analyst/` — the frozen cache is committed and is the only
  source of truth under replay.
- **`LLMCacheMiss`:** under `OMEGA_FROZEN_CACHE=1` a cache miss **raises**
  `LLMCacheMiss` (never falls through to a live call, never returns a neutral
  stub) — the V215 HTTP-guard philosophy applied to the LLM path. Cache-fill
  runs happen only with the flag OFF and a real `KIMI_API_KEY`.
- **Interface:** `ReasoningLayer.review_basket(cycle_ctx, candidates) -> BasketReview`
  — **per-cycle basket review**, not per-candidate. Rationale (Dispatch): one
  call per cycle is cheaper and gives the model a portfolio view (correlation,
  concentration, net exposure) that a per-candidate call cannot see.
- **Structured prompt** (forced JSON output schema):
  - cycle context + regime label (crisis/high_vol/normal→trend/recent mapping)
  - F&G + VIX (and the other V238 series values at this bar)
  - the full candidate list with per-signal breakdown (the composite members)
  - the last 10 cycles' basket PnL + running drawdown
  - 5 similar past decisions with their realized outcomes (nearest-neighbour on
    regime + candidate shape; retrieval is deterministic and frozen)
  - **output schema:** `{ "keep": [symbols], "drop": [symbols],
    "size_scale": {symbol: float in [0,1.5]}, "reasoning": str,
    "confidence": float }` — the quant book retains full veto (same subordinate
    posture as the V139 analyst: the layer can only trim/scale within
    pre-registered bounds, never invent a position).
- **Flag** `reasoning_layer_enabled`, default **OFF**. OFF-path must be
  **byte-identical to the V239 baseline** (unit test asserts identity; the
  layer is not even constructed when the flag is off).

## Execution plan (V240 = plumbing + smoke ONLY)

1. `omega/nodes/victoria/reasoning_layer.py` — `ReasoningLayer`, `BasketReview`,
   `LLMCacheMiss`; frozen-cache read/write; deterministic similar-decision
   retrieval; JSON-schema validation with a retry-on-malformed (bounded, then
   raise — no neutral fallback under frozen mode).
2. Wire behind `reasoning_layer_enabled` at the basket-assembly seam in
   `strategy.py` (after candidate generation, before sizing). OFF ⇒ construct
   nothing.
3. **Token:** `KIMI_API_KEY` lives in `~/projects/omega/harness/.env` (currently
   **empty** — must be populated with a real Moonshot key before the smoke).
   Never commit it; `harness/` is gitignored in omega. The reasoning layer reads
   it via `llm_analyst`'s existing env-var indirection.
4. **Smoke (single-window cache-fill, flag ON, `OMEGA_FROZEN_CACHE=0`):** run one
   recent window (~55–60 cycles). Verify: (a) Kimi determinism at temperature=0 —
   fill the cache, then re-run under `OMEGA_FROZEN_CACHE=1` and confirm every
   call is a cache hit and the run is byte-identical; (b) the `LLMCacheMiss`
   error path fires when a prompt hash is absent under frozen mode; (c) the
   committed `frozen_llm_cache/` manifest records the pinned served model id.
5. `check_determinism.sh` must PASS with the flag ON reading from the frozen
   cache (first LLM-in-the-loop determinism certification).

### Cost estimate

Per-cycle call ≈ ~2.5k input tokens + ~0.5k output. At `kimi-v2` pricing
($0.15/M in, $0.60/M out): ≈ **$0.000675/call** → a 55–60-cycle window ≈
**$0.04**. Dispatch's $0.30–0.50 smoke figure holds if v2.7 is ~5–8× the v2
price or prompts run larger; either way the single-window cache-fill is
sub-dollar. **Full-grid projection (V241):** 64 cells × ~55 cycles ≈ 3,500 calls
≈ **$2–4** at v2 pricing (record the actual once v2.7 price is confirmed; the
cache means each unique (cycle,candidates) prompt is paid exactly once ever).
