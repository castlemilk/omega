## Bisect result — NAMED CHANNEL

**Tool:** `scripts/trade_field_diff.py` (#13) on V220's existing `trend_OFF`
r1/r2 trade ledgers (no new run needed — the FAIL replicates already on disk).

**First divergent (trade, field):** cycle 4, **ARBUSDT long**, field **`size`**
— `5000.0` (r1) vs `6666.6667` (r2), |Δ| = 1666.67. Co-diverging: `pnl`,
`conviction`, `mae` (all downstream of `size`). **`entry_price` and `exit_price`
are bit-IDENTICAL** on this trade and everywhere — so the channel is in
**selection/sizing, NOT exit-price interpolation.**

**Root cause (traced, not guessed):** `size = conviction × notional`, and
`5000 : 6666.67 = 3 : 4` — a `budget/N` basket-normalisation ratio (N=4 vs N=3
long candidates). The signal fingerprint shows the *only* divergent signal field
is `basic_signals.value` at **sub-ulp** (~1e-18, near-zero) across cycles 1–200.
`basic_signals.value = tanh(fsum(composites)/len)` — V220 fenced *that* fsum
(`victoria_node.py:965`), so the divergence must enter through the per-ticker
`composite` inputs. Tracing upstream:

> **`omega/nodes/victoria/signal_generation.py:1160`**
> ```python
> _cs_raw = [(t, s) for t, s in signals.items() if ...]   # UNSORTED dict iteration
> _cs_vals = [s["composite"] for _, s in _cs_raw]
> _basket_mean = sum(_cs_vals) / len(_cs_vals)            # order-sensitive FP sum
> for _t, _ts in _cs_raw:
>     _ts["composite"] = _ts["composite"] - _basket_mean  # demeans EVERY ticker
> ```

The per-ticker composites are the **same multiset** (raw signals byte-identical),
but `_cs_vals` is summed in a **different order** across replicate processes
(`signals.items()` insertion order varies run-to-run) → non-associative FP gives a
sub-ulp-different `_basket_mean` → subtracted from every composite → a ticker whose
demeaned composite sits at ≈0 (the long/short boundary) **flips basket membership**
→ long basket N changes 4↔3 → `1/N` sizing jumps 5000↔6666 → cascades into the
$2,851 trend_OFF PnL spread and a downstream membership swap (cycle 154 vs 163).

**Same family as V211** (`basket_mean` at `strategy.py:2130`) but a **distinct
site**. This is the line **V213 tried with `sorted()` and REVERTED** — but V213's
sort was harmful *because the network + wall-clock + BLAS channels were still open*
and the re-order merely shifted the baseline onto them. Those are all closed now
(V214/V215/V216/V217/V220), so this site is finally the dominant residual.

**Named character of the channel:** it is a **selection-affecting** reduction
(basket demean), not a pure sizing arithmetic — V220's "sizing/exit magnitude"
framing was directionally right (it is downstream of the entry *count* decision)
but the mechanism is per-cycle basket *composition* flipping, which the locked
26/26 total count masked. The honest layer label is **cross-sectional
demean / candidate selection**, surfacing as `size`.

**Chosen target & fix:** `math.fsum(_cs_vals) / len(_cs_vals)` at
`signal_generation.py:1160`. Per the FP-order audit pattern, `fsum` (exact-rounded,
permutation-invariant) over `sorted()` — it closes the channel for the same
multiset regardless of iteration order **without re-ordering** (avoiding the V213
sort-shift failure mode). `math` is already imported in the module.

## Residual channel after the demean fence — funding z-score epsilon-guard amplifier

The post-fence grid (first run, 2026-06-12) reduced trend_OFF spread **$2,851 →
$255.59** but still FAILED the $200 floor (trades locked 25/25). Re-bisect on the
post-fix replicates:

- `trade_field_diff.py`: trade-set drift (ARBUSDT long c4↔c9, ADAUSDT long
  c13↔c15) + first divergent field c5 ETHUSDT short `size` (10299 vs 21977),
  `entry_price`/`exit_price` bit-identical.
- `signal_contribs.jsonl`: smoking gun — r2's c3 ETHUSDT trade carries an extra
  trace entry `funding_rate_signal = 0.408248` absent in r1. All later trades'
  traces identical. **0.408248 = √(2/3)/2 exactly.**
- NB `per_field_diff.py`'s "sub-ulp basic_signals.value" reading is structurally
  misleading here: the fingerprint is taken POST-demean, where mean(composites) ≈ 0
  by construction — O(0.1) raw-composite differences are recentered away. The
  aggregate signal fingerprint cannot see per-ticker presence flaps.

**Mechanism (reproduced exactly):** `FundingRateSignal._zscore_signal` guards
zero variance with `std = 1e-8`. For a **constant** cached rate r (frozen cache ⇒
every cycle reads the same row), `mean = fl(n·r)/n ≠ r` whenever n·r rounds in
binary (n=3,6,7,… for ETHUSDT's r=-7.52e-07). Every deviation is then the SAME
rounding residual, so variance ~1e-44 > 0 and **z collapses to exactly
±√((n-1)/n)** — the epsilon guard amplifies sub-ulp FP residue into an O(1)
signal that flickers with history length n. A ±1 compute()-call-count offset
between same-seed replicates (one swallowed read; `except Exception: pass` at
`signal_generation.py:916`) phase-shifts the flicker → the 13 divergent cycles.
One root explains the full residual spread.

**Fix:** constant-history fence in `signals/funding_rate.py:_zscore_signal` —
`if max(hist) == min(hist): return 0.0` (semantic: constant rate ⇒ no deviation
signal, at any n) + `math.fsum` for mean/variance. Unit-verified: constant rate
→ 0.0 for n=1..11; varying rates still produce nonzero signals.

**Sibling site (documented, not bundled):** `geometry/market_manifold.py:424`
has the identical `else 1e-8` pattern; its inputs are price-derived (non-constant
in practice) so it is dormant — queue for inspection if any cell still FAILs.
