## Pre-registration summary (what V256 was going to be)

Track C from V254 scoping: treat **on-chain flow as a primary signal universe** — a
strategy whose *entries are driven by flow*, not a feature bolted onto the momentum
composite (the V240-B whale-flow rehab). Pre-declared composite of **4 flow signals**,
built cross-sectionally across the selective universe, walk-forwarded and gated exactly
like the spot book:

1. **Net exchange inflow/outflow** (per asset) — coins moving on/off exchanges as a
   supply-pressure proxy.
2. **Active-address velocity** (per asset) — network-usage momentum.
3. **Whale-cluster movement** (per asset) — large-holder accumulation/distribution.
4. **Stablecoin supply change** (mint/burn) — dry-powder / risk-appetite proxy,
   intended **per-chain / cross-sectional** to feed the cross-sectional demean.

The independent-N story (why Track C ranked #1-offline): a flow-primary book trades a
mechanism ~uncorrelated with the directional composite, so its recent-regime windows
are statistically independent of the spot book's N=4 — a genuine escape from the R1
noise-floor wall, not a signal bolted onto the saturated composite.

## Why the one available signal fails the pre-registered design

`stablecoin_total_usd` is a **single market-wide scalar**, but V256's design is
**cross-sectional** — it needs per-asset (or at least per-chain) series so the
composite can rank names against each other and feed Victoria's cross-sectional demean
(`signal_generation.py:_basket_mean`). A market-wide aggregate carries **no
cross-sectional information**: it can only say "risk-appetite up/down" for the whole
book at once, which is a **market-timing / regime overlay**, not a name-selection
signal. It cannot drive a flow-*primary* universe of the kind Track C pre-registered.

Independent-N spirit: the whole reason Track C ranked #1-offline is that a flow-primary
book manufactures **new independent recent windows** by trading a different mechanism
per name. A single market-wide scalar manufactures **exactly one** timing series shared
across all names — it does not create independent per-asset structure, so it does not
attack the recent-N=4 wall the way the pre-registered design claimed. It fails the
independent-N *spirit*, not just the letter.

## Anti-Goodhart note — what we are deliberately NOT doing

There is a tempting salvage: redefine V256 down to a **1-signal market-timing test**
using `stablecoin_total_usd` as a whole-book risk-on/risk-off gate. **We are not doing
that.** It would be a **post-hoc redesign** — swapping the pre-registered 4-signal
cross-sectional flow-primary universe for a completely different single-scalar overlay
strategy *after* seeing that the cross-sectional data is missing. That is textbook
Goodhart/HARKing (R4 in the V254 refutation ledger): fitting the hypothesis to the
data that happens to be on disk rather than acquiring the data the hypothesis
pre-declared. A whole-market stablecoin overlay is also structurally a **regime-gate
feature on the existing universe** — which inherits the same R1 noise-floor + R2
saturation deaths that killed V241/V245, judged at N=4. If a stablecoin-supply overlay
is ever worth testing, it gets its **own** pre-registration with its **own** falsifier,
not a quiet rebranding of V256.
