## §1 — What this is, and what it explicitly is NOT

**NOT a rehabilitation of the reasoning layer.** V241 measured per-cycle basket review on
the full 32-window walk-forward grid and refuted it — *"ACTIVE but adds variance, not
expectancy"* (recent mean-Δ +$226.56 vs a >+$400 bar; recent p25-Δ −$705.44 vs >+$500).
V258's specialist-ensemble rehabilitation was refuted at Phase 0 for $0 grid spend.
`reasoning_layer_enabled` stays `False` (`features.py:958`) and **V281 does not propose
turning it on.**

**IS a provider.** `reasoning_layer.py` can only talk to the `agy` CLI: `__init__` raises
on any `model_id` absent from `_AGY_MODEL_STRINGS` (`:44-48`), a closed dict of three
Gemini strings. There is no local-model path anywhere in the repo (`llm_shell.py` has no
ollama/vLLM/localhost hooks). This machine already runs `ollama` with
`qwen3.8:27b-mlx`, `qwen3:14b`, `gemma3:27b`.

**Why it is worth building even though the hypothesis is refuted.** V241/V258 were
shaped by their provider: V258's Phase 0 is labelled *"$0-grid, agy-wall-clock only"*,
and V240 notes the CLI *"exposes no temperature control, so live-call determinism is NOT
assumed."* A local provider removes all three constraints — free unlimited cache-fill
across all 32 windows, `temperature=0` + fixed `seed`, and a **separate `thinking`
field** the API returns alongside `response` (verified). None of that was available to
the refuted experiments. It makes future hypotheses cheap to test; it does not make the
dead ones alive.

## §2 — Design constraints (each forced by existing contracts)

1. **Subprocess, not in-process HTTP.** The V215 fence intercepts urllib/requests inside
   the run. V240 used an `agy` subprocess precisely because the fence *"does not and
   should not intercept"* it. The ollama provider therefore also calls out via
   subprocess. It is not a fence bypass: cache-miss under `OMEGA_FROZEN_CACHE=1` still
   **raises `LLMCacheMiss`**, so live calls happen only during explicit
   `OMEGA_LLM_CACHE_FILL=1` runs, and an LLM prompt is not market data.
2. **Cache namespace is `model_id`.** Each provider/model gets its own directory under
   `data/frozen_llm_cache/`, so the 693 committed `gemini-3.1-pro-low` entries are
   untouched and un-shadowed.
3. **The V241 posture is preserved unchanged.** `size_scale` stays clamped `[0, 1]` —
   trim or scale down only, never invent or up-size. The provider changes *who answers*,
   never *what the answer is allowed to do*.
4. **Thinking is captured, never trusted.** The trace is recorded for audit; the typed
   contract (`keep`/`drop`/`size_scale`) remains the only thing that can affect a
   position.

## §5 — Results

All five gates PASS. 8 unit tests + one live model call + one sentinel run.

### G1 — PASS (backwards compatibility)

`gemini-3.1-pro-low` still constructs, still reports `_provider == "agy"`, still resolves
`"Gemini 3.1 Pro (Low)"`. Cache directories are namespaced per `model_id`, so the 693
committed entries are neither shadowed nor touched. `qwen3.8-27b-mlx` now constructs
where any non-agy id previously raised `ValueError`; an unknown id still raises.

`_AGY_MODEL_STRINGS` was folded into `_PROVIDERS` rather than kept alongside it — it had
exactly one reference (its own definition) after the change, and two registries naming
the same thing is the drift V276/V277 spent two versions closing.

### G2 — PASS (the hermetic contract, per-provider)

With `OMEGA_FROZEN_CACHE=1` and an empty cache, the **local** provider raises
`LLMCacheMiss`, and `_invoke_provider` is asserted **not called**. This is the gate the
whole design rests on: it proves the property is a property of the *layer*, not an
accident of the agy path.

### G3 — PASS (bounded authority)

A model returning `size_scale: {"ETHUSDT": 4.0}` is still clamped to `1.0`; `keep`/`drop`
are still validated as subsets of the candidates. A local model is not more trusted than
a frontier one — the provider changes *who answers*, never *what the answer may do*.

### G4 — PASS (live, against the real model)

`qwen3.8:27b-mlx`, one basket review, **30.0 s**:

| | |
|---|---|
| keep / drop | `["AVAXUSDT"]` / `["ETHUSDT", "SOLUSDT"]` |
| size_scale | `{"AVAXUSDT": 0.4}` — within [0,1] |
| confidence | 0.83 |
| thinking | **2,444 chars captured** |
| cache | `a69cf42267ffe04f.json` + `MANIFEST.json` written |

Given a crisis context (bear_prob 0.71, drawdown 0.13), it dropped two low-conviction
longs, kept the aligned short, and scaled it to 0.4 — behaviour inside the subordinate
posture without being told the bounds in those terms.

**Recorded so it is not mistaken for a result:** this is one prompt, proving the
*provider* works. It is not evidence about the reasoning hypothesis, which V241 refuted
on 32 windows and V258 refuted at Phase 0.

### G5 — PASS (standing path untouched)

crisis $1,082.80 / trend $4,679.67 / recent $824.81 — to the cent, $0.00 determinism.
The flag is OFF and V281 ships it OFF.

## §6 — Conclusion

**Shipped: the reasoning layer can now talk to a local thinking model, and every contract
that made it safe still holds.**

The valuable part is what it does to *cost*. V258's Phase 0 was scoped "$0-grid,
agy-wall-clock only", and V240 recorded that the CLI "exposes no temperature control, so
live-call determinism is NOT assumed". Both constraints are now gone: cache-fill is free
and unlimited, sampling is `temperature=0` at a fixed seed, and the model returns a
**separate reasoning trace** that can be audited rather than inferred. A 32-window fill
that was previously a budget question is now a wall-clock one (~30 s/call).

**What has NOT changed: the hypothesis is still refuted.** V241 measured whole-basket
review distributionally and found variance without expectancy; V258's rehabilitation died
at Phase 0; V260's LLM regime classifier was degenerate. `reasoning_layer_enabled` stays
`False`. A cheaper model is not a new hypothesis — it is the same hypothesis with a
smaller bill, and V258 already ran that shape.

The honest framing of this version: it lowers the cost of *asking*, and answers nothing.

**Standing baseline: UNCHANGED and NOT edited.**

## §7 — Next steps for V282

1. **A genuinely new reasoning hypothesis, or none.** The untried shapes are: reasoning
   on **exits** rather than entries; **veto-only** overlay on an existing gate; regime
   labelling with a causally-computable target (V260 refuted the *news* variant, not the
   idea). Anything resembling V241's whole-basket review should not be pre-registered.
2. **The world-knowledge lookahead is unaddressed.** The hermetic cache makes an answer
   *reproducible*, not *causal*. A model trained past the replayed bar knows what
   happened — V273's H1/H2 class in its purest form. Any future reasoning pre-registration
   must state this explicitly; V281 did not need to, because it turns nothing on.
3. **Do not fill a 32-window cache speculatively.** ~2k calls at ~30 s is ~17 h of
   wall-clock for a hypothesis that does not yet exist. Fill after a pre-registration,
   not before.
