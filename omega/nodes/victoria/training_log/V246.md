## Hypothesis (one sentence)

Per-trade exit rules — a hard MAE stop at a fraction θ of notional and/or an
MFE trailing lock (trigger m, retracement cap r) — cut the left tail of the
per-window PnL distribution (losers currently realize 100% of their worst
excursion) by more than they cost in winners cut short, lifting pooled p25 and
the recent regime's cushion.

## Protocol (in order; each step gates the next)

1. **$0 offline counterfactual scorer** (`scripts/v246_exit_scorer.py`) on the
   EXISTING 32-window V240 confirm ledgers (343 trades; columns
   `mae`/`mfe`/`win_capture`/`loss_capture` are dollar extremes over each
   trade's life — semantics per `exit_controller.py` docstring). Rule
   families, all per-trade transforms with subsequent trades held fixed (no
   re-entry/budget modeling — noted as a scorer limitation):
   - **A. Hard MAE stop** (path-safe, conservative): if `mae ≤ −θ·size` then
     `pnl' = −θ·size` else `pnl`. Sweep θ ∈ {1%, 2%, 3%, 5%} of notional.
   - **B. MFE trailing lock** (mildly optimistic — ignores gap-through): if
     `mfe ≥ m·size` then `pnl' = max(pnl, (1−r)·mfe)`. Sweep
     m ∈ {1%, 2%, 3%} × r ∈ {0.25, 0.5}.
   - **C. A+B combined** (top-2 A cells × top-2 B cells).
   - **D. Regime-conditional** variants of the best pooled cell (crisis-only /
     recent-only / non-trend), scored the same way.
   Report per-regime window-PnL mean/p25/p50/p75 deltas per cell + fire rates.
2. **Sanity gate (pre-registered, same bar as V244):** ≥1 cell must show
   pooled p25-Δ > +$100 AND recent mean-Δ > +$100. A pass carried ONLY by
   family B (the optimistic transform) is recorded as upper-bound-only and
   requires an A-or-C cell within 50% of the bar to proceed. **No cell passes
   ⇒ V246 REFUTED AT $0** — and the stagnation reflection fires (3rd
   consecutive post-REFLECTION_V241 refutation): write `REFLECTION_V246.md`
   BEFORE any V247 pre-registration.
3. **Implementation** (only if gate passes): map the winning cell onto the
   EXISTING `ExitController` config (θ/m/r as notional-fraction parameters —
   add a notional-fraction mode beside the ATR mode if the ATR mapping cannot
   express the winning rule; flag stays `disposition_exit_controller`,
   default OFF, OFF byte-identical to baseline, smoke-verified).
4. **32-cell frozen walk-forward grid** (V245 pattern: ON vs reused V240
   confirm baseline, N=2 sentinels, `$AUDIT/v246/`, committed-state restore,
   `TMPDIR=$AUDIT/tmp`), top-1 cell (or top-2 as V246.A/B matrix if two
   disjoint-family cells clear the gate).
