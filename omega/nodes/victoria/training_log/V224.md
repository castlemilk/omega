## Methodology spec (Plan agent, grounded in the actual consumer + replay cursor)

1. **IC definition.** Per `(regime, signal)` IC = **Spearman rank correlation**
   between the signal's `raw_value` at cycle *t* and the **1-bar-forward simple
   return** of the ticker that produced it, pooled over all (cycle, ticker)
   observations whose runtime regime label equals `regime`. Horizon = **1 bar**
   (the replay cursor advances exactly one bar/cycle; the only horizon with no
   overlapping-window autocorrelation). Forward return computed **directly from
   the frozen snapshot close series** (`close[i+1]/close[i] − 1`), NOT from
   realized PnL (PnL is confounded by sizing/filters/the gate). Signal value =
   `raw_value` from each `SignalTrace` (the pre-weight value in [−1,1] the
   consumer multiplies by IC). IC sign kept (consumer's `fv*ic` inverts
   anti-predictive signals; noise floor `abs(ic)<1e-4`).

2. **Holdout / OOS protocol — leave-one-snapshot-out (LOSO) pooling.** ICs used
   while trading snapshot *X* ∈ {trend, crisis, recent} are fit **exclusively on
   the other two snapshots** (trend ICs fit on crisis+recent, etc.). Zero
   look-ahead by construction AND doubles per-cell N (mitigates thin cells).
   Rejected: (b) early in-sample slice (wastes regime-rich early cycles, still
   trades a seen distribution); (c) expanding-window online (injects a mutable
   per-cycle accumulator into the hot trading path — multiplies the determinism
   surface V211→V221 spent six channels closing). LOSO keeps estimation **fully
   offline** — the JSON is frozen before the run starts. Corpus = the
   `DecisionSnapshot` JSONL (regime + per-ticker `signal_traces[].raw_value` per
   cycle) from a deterministic IC-off replay of each snapshot, joined to that
   snapshot's close series for forward returns via the exact replay cursor walk
   (`cursor` starts at `window=30`, `i(cycle)=cursor−1`, wraps to `window` when
   `cursor>series_len`).

3. **Regime keying.** Bucket every (cycle, ticker) observation by its **runtime
   `_regime` label** (lowercased) into `{normal, crisis, high_vol}` — never by
   snapshot name (each snapshot is a runtime-regime *mix*: trend ≈48%
   crisis/high_vol, recent ≈57%). Output `{signal: {regime: ic}}`, identical in
   shape to `seeded_regime_ics`. Labels outside the three keys are not written →
   consumer's `.get()→None` falls back to pooled.

4. **Min-sample guard.** `N_min = 30` obs per (regime, signal) cell. Below 30,
   **omit the key** (consumer falls back to pooled IC via existing `.get()→None`).
   SE(ρ)≈1/√(N−1)≈0.19 at N=30 — the floor below which a per-regime IC is noise
   vs the pooled prior. Matches the pipeline's `_MIN_WINDOW=30`. LOSO pooling
   pushes most cells above 30; thin cells degrade gracefully to pooled.

5. **Rank tie-break.** **Ordinal ("first") ranks over a pinned secondary key**,
   NOT average ranks. Sort observations by `(value, cycle, ticker)` ascending,
   assign ranks `0..N−1` by position — a unique deterministic total order even
   when many `raw_value`s collide (signals quantize). Average ranks reintroduce
   an order-sensitive float division; ordinal-with-pinned-key is integer-rank,
   byte-reproducible. Applied identically to signal-value and forward-return
   ranks.

6. **Accumulator fencing.** Spearman computed as Pearson on integer ranks (the
   `d²` shortcut is invalid under ordinal ties). Every float sum uses
   `math.fsum` over the **pinned `(cycle, ticker)`-ordered** observation list:
   `mean_rank = fsum(ranks)/N`, `cov = fsum((rx−mx)(ry−my))`, `var_x/var_y =
   fsum((r−m)²)`, `ic = cov/√(var_x·var_y)` (guard `var==0 → omit`). No builtin
   `sum`/`np.sum`/`scipy.stats.spearmanr` (unpinned tie + BLAS reduction).
   Hand-rolled on Python floats.

7. **Output schema** — `data/empirical_ic_history.json`, one committed file with
   a per-target block (LOSO), read under `OMEGA_R3_ICS=1`; loader selects the
   block by snapshot name (trending→trend, crisis→crisis, else→recent), mirrors
   `seeded_regime_ics`/`seeded_pooled_ics` shape so the consumer slot is
   untouched. Keys sorted, floats default-repr → stable bytes.

   ```json
   {
     "_provenance": {"version":"V224","method":"LOSO Spearman, 1-bar fwd ret, ordinal (value,cycle,ticker) tie-break, fsum-fenced","horizon_bars":1,"n_min":30},
     "trend":  {"fit_on":["crisis","recent"], "empirical_regime_ics":{"sma_crossover":{"normal":0.41,"crisis":0.18,"high_vol":0.22}, "...":{}}, "empirical_pooled_ics":{"sma_crossover":0.34, "...":0.0}, "_sample_counts":{"sma_crossover":{"normal":412,"crisis":188,"high_vol":96}}},
     "crisis": {"fit_on":["trend","recent"], "...":{}},
     "recent": {"fit_on":["trend","crisis"], "...":{}}
   }
   ```

8. **Comparison reporting** (estimate_ics.py stdout, sorted order): per-regime
   sample counts + cells written/omitted; per-regime IC dist (min/median/max,
   #negative, #below 1e-4 floor); side-by-side `signal | regime | seed→empirical
   | Δ` with **sign-flips flagged**; coverage delta (cells empirical fills that
   seed left to pooled, and vice-versa).

## Pre-committed risks + mitigations

- **Thin per-(regime, signal) cells in 200-cycle snapshots → noisy ICs.**
  Mitigation = LOSO pooling (fit on 2 snapshots ≈ doubles N) + N_min=30 omit-cell
  fallback to the pooled prior. Documented sample counts surface any thin cell.
- **`high_vol` is the rarest runtime label** → its column may be mostly pooled
  fallback. Acceptable: the V223 gate *bypasses* crisis/high_vol anyway, so the
  high_vol IC column is only consulted on the rare non-bypassed path; the
  decisive PnL lives in the `normal` column (the 121 crisis-snapshot normal
  cycles V223 couldn't fix).
- **Empirical ICs give more signals non-zero per-regime weight than the 2-signal
  seed table** → more signals enter the weighted composite → a near-boundary
  selection could flip, risking a determinism FAIL. Mitigation = the consumer is
  already fsum-fenced; if a new channel surfaces, the trade-diff names it.
- **Forward-return sign on shorts.** IC is computed on the raw signal vs raw
  price forward return (direction-agnostic); the consumer applies the signal's
  own sign downstream. No per-side IC — pooling longs+shorts of the same ticker
  is correct because the signal value already encodes direction.

## Conclusion

**Fork: ELSE branch fires → IC RETIRED (third refutation).** R3 empirical ICs —
fit on a leave-one-snapshot-out OOS holdout, the strongest IC source available —
beat within-grid equal-weight on only **1 of 3** gates (needed ≥2). This is the
third consecutive refutation of IC weighting vs equal-weight: V222 (always-on
seed), V223 (regime-gated seed), V224 (regime-gated **empirical-OOS**).

**Mechanism (consistent across all three IC incarnations): IC weighting helps
trend, hurts crisis, is a wash on recent.** The trend edge is real and now
3×-replicated (V222 +$3,331, V223 preserved, V224 +$2,206 vs equal-weight, both
arms hermetic). The crisis damage lives in the **121 *normal*-labeled cycles of
the crisis snapshot** that the regime gate leaves IC-on — and the decisive finding
is that **empirical re-estimation did NOT fix them**: empirical narrowed the
crisis loss vs seed (+$1,860) but crisis is still −$2,808 *worse* than
equal-weight. The harm is **conviction concentration itself** (loading
`sma_crossover`/`ricci` over a flat basket), not wrong IC magnitudes — better ICs
hurt less but still lose. recent is within noise (−$190, inside the $200 floor).

The hypothesis "empirical ICs were the missing piece" is **refuted**. IC weighting
is retired as a global strategy. V221-era equal-weight (IC-off) stays main; the
`regime_conditional_ic_weighting` gate + `OMEGA_R3_ICS` path are mothballed
(flag-default-OFF, code dormant — preserved only as the substrate for a possible
future *trend-only* IC application, the single durable IC finding).

All falsifier sub-conditions held: 9/9 determinism PASS (no near-boundary channel
from empirical ICs); `estimate_ics.py` byte-reproducible (commit 72ca4fa tests).
No high-water (R3 net −$998 < equal-weight net −$205; no per-gate record broken —
eqw_recent +$4,747 < V221-era recent high +$4,901).
