## 3. Phase-0 feasibility gates (both must PASS before activation)

Scorer: [`scripts/v268_soak_feasibility.py`](../../../../scripts/v268_soak_feasibility.py) ·
artifact `data/v268_soak_feasibility.json` · $0, no network, no RNG.
Reuses `v267_capacity.py`'s ADV loader so the tercile cut is **identical** to
the one G3 was scored against.

### F1 — ACCRUAL. Can the calendar supply the blocking quantity in time?

Sharpe CI width scales ≈ 1/√n, so `n_req = n₀ · (w₀ / w_target)²`.

- **Bar:** the horizon to reach CI width < **1.0** must be ≤ **3 years**,
  measured at the empirical arrival rate of high-ADV-tercile funding-carry
  trades in the recent era (best of the last-12m / 24m / 36m rates).
- **Falsifier:** if the best-case horizon exceeds 3 years, the soak cannot
  adjudicate G3 on any decision-relevant timescale → **R3 (calendar-bound N)**,
  and activating it under a "few months out" framing would be Goodhart.

### F2 — PAYLOAD. Does *scaled* notional measure anything *unit* notional doesn't?

- **Bar:** `max |Sharpe(k) − Sharpe(1)|` across k ∈ {1, 10, 100, 315.9, 1000}
  must exceed **0.01**.
- **Falsifier:** if Sharpe is invariant in k, then "scaled" is an empty
  adjective — the harness has no impact model (V267 §1 declared the fitted-impact
  lane **R4**: no depth data, no fills above the $10k cap), so per-trade PnL is
  exactly linear in notional and every ratio statistic cancels. Running the lane
  at $1M/trade would produce a number *labelled* capacity-relevant that carries
  no capacity information → **R5 (structural payload)**.

## 4. If Phase 0 passes — the soak's own pre-registration

Recorded now so it cannot be shaped later.

- **Activation:** funding-carry lane added to daemon PID 10329 as a **second
  book**. The Victoria lane's cycle function, universe, sizing and checkpoint
  fields are **not touched**; the standing baseline (crisis +$599 / trend
  +$2,997 / recent +$30) **must not move**.
- **Determinism / observability:** seed-pinned; checkpoint stays MD5-chained
  (`<date>.json` + `.json.md5`) at `schema_version: 2`; the lane writes the
  `v255c_trades.csv` 14-column schema so `v267_capacity.py` reads it unmodified.
- **Kill-switch:** if the lane's paper drawdown on any observation window
  exceeds V267's measured slippage budget (**11.83 bps**), halt **the lane
  only** — never the daemon, never the Victoria lane — and surface.
- **Reading gate ("done reading"):** the first observation window at which the
  top-liquidity-tercile `recent` Sharpe CI width falls below **1.0**. Until
  then the lane is accruing, not adjudicating, and **no verdict may be read
  from it** — partial reads are the R1 pattern this campaign has killed twice.
- **Absolute guardrails:** live-PAPER only. No broker. No orders. No funds. No
  scaling on a real venue. `harness/.env` untouched.

## 5. What would convince us this version was wrong

- F1 passes but the realised forward arrival rate is < ½ the projected rate
  after 2 quarters → the projection was non-stationary; re-audit before
  continuing to spend host time.
- The lane's forward trades do not reproduce the ledger's regime mix or funding
  distribution → the live feed and the frozen archive disagree, which is a
  V251-class reconciliation defect, not a strategy finding.
