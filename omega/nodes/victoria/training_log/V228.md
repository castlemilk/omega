## Hypothesis

The two best-performing overlays in the V223→V227 arc target **disjoint regimes via
disjoint mechanisms** and should therefore **compose additively**:

1. **Drawdown-gated crisis-skew** (SHIPPED V227, default ON): a one-sided realized
   downside-semivariance brake that fires only when `regime ∈ {crisis,high_vol}` AND
   per-ticker realized recent drawdown > 12%. It shifts the per-ticker `composite`
   (selection/direction) on the deepest-drawdown crisis cycles. Banked effect:
   **crisis +$630** vs within-grid both-OFF equal-weight.
2. **Trend-IC overlay** (R3 empirical ICs, V224, banked +$2,206 hermetic): a
   regime-conditional IC re-weighting of the **conviction filter** in
   `strategy._compute_weighted_conviction` (IC-on in trend/bull/normal, equal-weight
   bypass in crisis/high_vol). It re-weights conviction toward the empirically
   highest-IC signals on trend cycles. Banked effect: **trend +$2,206** vs equal-weight.

The bet: turning **both** ON simultaneously lets each keep its banked edge on its own
target gate — crisis brake → crisis, trend IC → trend — because they touch different
code paths (signal_generation.py per-ticker `composite` vs strategy.py conviction
filter), different regimes (crisis-only skew vs trend/normal-only IC), and different
signal classes (realized semivariance vs cross-signal IC weighting). The handoff
between them is the per-ticker `composite` field (skew writes it, IC reads it); there
is no shared float-reduction site, so no new determinism channel is expected.

### Orthogonality / interaction hypotheses

- **H0 (additive, SHIP):** crisis Δ ≈ V227's +$630 (the IC overlay bypasses to
  equal-weight in crisis, so it should not touch the crisis brake), AND trend Δ ≈
  +$2,206 (the crisis brake near-inerts on trend — V227 `skew_on_cycles`=12 on trend),
  AND recent within ±$200.
- **H1 (IC steals from crisis):** the IC overlay's crisis/high_vol *bypass* denylist
  is per-cycle on the runtime label, not the snapshot — so on the crisis snapshot the
  ~121 *normal*-labeled cycles run IC-on. If those normal-labeled crisis cycles
  interact with the skew-shifted composite, crisis could regress below V227's +$630.
- **H2 (skew interferes with trend IC):** the crisis brake fires 12 cycles on trend
  (V227); if those 12 cycles are exactly where the IC overlay earns its edge, the
  trend IC gain could shrink below +$2,206.

### Decomposition — additive, not interactive

The stack is **clean additive composition of two independent effects**, one of which is
net-negative. Reconciling against the banked standalone numbers:

- **trend:** stack-ON **+$875.16** ≈ V224 R3-IC-ON **+$875.14** *to the cent*. The skew
  is inert on trend (on_cycles=12, V227 showed +$0.02), so trend is **purely the IC
  overlay reproducing V224 exactly.** The Δ vs baseline (+$1,093) differs from V224's
  +$2,206 only because the V224 baseline was a different commit (−$1,330 vs −$217.71);
  the *absolute* IC-ON trend number is identical → strong reproducibility confirmation.
- **crisis:** predicted = baseline −$3,621.25 + skew(V227) +$630.08 + IC(V224 R3) −$2,808.12
  = **−$5,799.29**; observed **−$5,613.82** (a tiny *favorable* interaction +$185, swamped).
  The IC overlay's crisis harm dominates the skew's crisis help by ~4.5×.
- **recent:** baseline +$4,901.01 + skew(V227) −$64.33 + IC(V224) −$190.13 ≈ **+$4,646.55**;
  observed **+$4,492.22** (−$154 residual). Both components mildly negative; sum < −$200.

So there is **no surprising interaction site** — the V227 brief's technical question
("do the two overlays compose without a new determinism channel?") is answered **yes,
they compose, deterministically**. The experiment's *strategic* finding is that the
trend-IC overlay **is not regime-orthogonal in net**: its crisis/high_vol bypass is
per-cycle on the runtime label, so 121/200 crisis-snapshot cycles are *normal*-labeled →
IC-on → conviction concentration → the V224 crisis loss, which no crisis-skew gain offsets.
