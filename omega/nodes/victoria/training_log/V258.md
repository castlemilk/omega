## Hypothesis (one sentence)

Replacing V241's single-basket-review LLM call with a **specialist ensemble** (one
prompt per signal class scoring per-name conviction 1–5, then a meta-prompt that
aggregates) produces per-cycle interventions with higher correlation to realized PnL
than V241's whole-basket 42.6% drop rate showed — i.e. the generalist's failure was
one-agent-reviews-everything, not LLM-review-per-se.

## Pre-declared parameters (LOCKED before any run)

- **Specialist prompt architecture:** one prompt per `{fear_greed, VIX+DXY macro,
  yield_curve, funding+OI, gdelt-news}` scoring per-name conviction on a **1–5 scale**,
  then a **meta-prompt** that aggregates the five specialists' per-name scores into a
  keep/drop/size_scale decision.
- **Posture (identical to V241):** drop/scale-only — never invent, never flip a side,
  never up-size past the strategy's proposed weight. `size_scale ∈ [0, 1]`.
- **Model (identical to V241):** Gemini 3.1 Pro via the `agy` CLI, `gemini-3.1-pro-low`
  (`_AGY_MODEL_STRINGS["gemini-3.1-pro-low"] = "Gemini 3.1 Pro (Low)"`, agy 1.1.1).
- **Hermetic cache (identical to V241):** `data/frozen_llm_cache/{model_id}/{prompt_hash}.json`,
  `prompt_hash = sha256(canonical_prompt_json)[:16]`; `LLMCacheMiss` under frozen mode.
- **Interface:** extend `reasoning_layer.py` (`SpecialistEnsemble` reuses `_prompt_hash`,
  `_cache_load/_store`, `_extract_json`, the frozen-mode contract). Do NOT rewrite
  `ReasoningLayer`.

## Falsifier (pre-registered — HARD, checked in order)

### Phase 0 — divergence probe (the gate; $0-grid, agy-wall-clock only)

Replay a stratified sample of V241's cached decision cycles through the specialist
harness and compare the ensemble's per-name keep/drop decision against V241's
whole-basket cached decision. **REFUTED at Phase 0 (no grid) if ANY holds:**

1. **Divergence < 5%** — specialist ensemble per-name decisions are (near) byte-identical
   to the whole-basket review. The reframing adds nothing.
2. **Phase-0 intervention rate on the new specialist prompts < 20%** — mostly-no-op
   specialists = inert scaffolding, not a signal source.
3. **Input-starvation** — the payload the specialists condition on carries no
   per-signal-class fields (see "Structural Phase-0 input audit" below); any divergence
   is then necessarily prompt-wording sampling noise, not signal, and cannot be
   distinguished from V241's variance-for-nothing failure.

### Post-Phase-0 grid (only if Phase 0 clears)

32-window walk-forward, `Δ = specialist_on − universe_selective`. REFUTED if:
- **recent mean-Δ ≤ +$100** OR **recent p25-Δ ≤ +$400** OR **trend/crisis Δ < −$300**.

Note the recent bar (+$100 / +$400) is **intentionally looser** than V241's
(+$400 / +$500): V247 established the +$100 recent mean-Δ is already below the 2·SE
$727 noise floor. V258 tests **signal existence**, not magnitude — a magnitude claim is
structurally unfalsifiable on the current manifest (V249 calendar-bound recent N).

## Structural Phase-0 input audit (read-only, $0 — completed 2026-07-14)

Before building anything, audit what the specialists can actually condition on. All
**692** V241 frozen-cache entries (3,427 candidate slots) were inspected:

- **Candidate fields (uniform, 3427/3427):** `{composite, conviction, side, symbol}`.
- **cycle_ctx fields (uniform, 692/692):** `{bear_prob, bull_prob, cycle, regime}`
  (`drawdown`/`recent_basket_pnl` appear in exactly 1 sentinel entry).
- **EXTRA per-signal-class fields:** **NONE.** No `fear_greed`, `vix`, `dxy`,
  `yield_curve`, `funding`, `oi`, or `gdelt` value appears per-name or per-cycle
  anywhere in the payload.

**Implication for the hypothesis:** every signal is collapsed by the strategy into a
single `composite` scalar per candidate *before* the reasoning layer sees it. A
`fear_greed` specialist replaying V241's cached decisions has no fear_greed input; a
`funding+OI` specialist has no funding or OI input. All five specialists receive
**byte-identical inputs** and can differ only in prompt wording. This makes falsifier
clause (3) the binding one *by construction*: the specialist reframing is
input-starved on V241's payload. Injecting real per-signal-class breakdown would
require (a) data absent from the cache — so it is not a replay of V241's decisions but
a full new experiment/re-fill — and (b) touching Victoria signal/features code, which
this task's guardrails forbid.

The empirical probe below is run anyway (measure before asserting) to put a number on
the divergence and confirm it is either < 5% (clause 1) or pure wording-noise.

## Conclusion

- **The two numeric clauses did NOT fire** — the specialist ensemble diverges from V241's
  whole-basket review on **37.8%** of per-name decisions and intervenes on **49.6%** of
  slots. Naïvely that "looks like" the reframing changed something.
- **But that divergence is provably non-informational.** The $0 structural audit
  (all 692 cache entries) established the LLM payload carries only
  `{composite, conviction, side, symbol}` per candidate — every signal is collapsed into
  one `composite` scalar *before* the reasoning layer. The five specialists therefore
  receive **strictly ≤ the generalist's information** (identical payload, narrower prompt
  framing). A `fear_greed` / `funding+OI` / `gdelt` specialist has **no** fear-greed /
  funding / news value to condition on. The 37.8% divergence is the model sampling
  differently across differently-*worded* prompts over **identical data** — prompt-wording
  variance, not signal. This is V241's own diagnosis ("a high-activity repricer that
  reshuffles PnL without information; variance for nothing", pooled Δ +$31, spread $27k)
  reproduced at **6× the cache-fill cost**.
- **Hypothesis REFUTED.** V241 did not die from *one-agent-reviews-everything*; it died
  because the LLM sees a post-collapse composite with no signal-class structure to reason
  over. Decomposing the *reviewer* cannot recover structure the *payload* already threw
  away. Per V241's own queue rule ("do not re-grid on hope"), the ~26h specialist
  cache-fill + 32-window grid is **not run** — the distribution it would measure is
  predictable variance-for-nothing.
- **No high-water impact.** Standing spot baseline (crisis +$599 / trend +$2,997 /
  recent +$30) untouched; flags unchanged; `reasoning_layer_enabled` stays OFF.
