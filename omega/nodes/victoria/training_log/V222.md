## Hypothesis

The strategic audit's central finding (`STRATEGIC_AUDIT_2026-06.md` §1.2): the
conviction measure is a **flat unweighted composite** of one verified-alpha
signal (`sma_crossover`) averaged 1:1 with two research-flagged dead-weight
signals (`fear_greed_signal`, `ollivier_ricci_signal`), because

1. `_signal_ics` is empty — `update_signal_ics` has **zero callers** in the
   training path (V218.B probe: `IC-WEIGHTING INERT` at every startup), and
2. `_compute_weighted_conviction` early-returns the raw composite at
   `strategy.py:1032` whenever `_signal_ics` is empty.

**Bet:** with the IC subsystem actually running — pooled + per-regime seed ICs
loaded at startup, the early-return removed, per-regime weighting declared and
ON — the conviction filter down-weights the dead signals (IC 0.0 → excluded)
relative to `sma_crossover`, and **at least one gate moves > $100 from the V221
hermetic baseline**. Most likely effect: **recent goes UP** (sma_crossover gets
dominant weight where the composite was most diluted); trend may improve too.

This is a SUBSTANTIVE strategy bet (changes the conviction formula), not eval
substrate. It is measurable only because V221 made the eval hermetic ($0.00
noise floor — any nonzero Δ is real; the $100 falsifier bar is conservative).

## Implementation plan (3 sub-steps — ALL needed, else V218.B inertness trap)

1. **Seed `data/signal_ic_history.json`** with pooled + per-regime IC
   estimates under new top-level keys `seeded_pooled_ics` /
   `seeded_regime_ics` (the existing `signals` key remains the
   SignalDecayDetector's observation store; `SignalDecayDetector.persist()`
   is patched to preserve unknown top-level keys so a run does not wipe the
   seeds). Loader added to `run_training.py` (gated by new feature flag
   `ic_seed_weighting`, default ON) calls `update_signal_ics` +
   `update_regime_ics` after strategy build, BEFORE the V218.B probe — so the
   probe line flips from `IC-WEIGHTING INERT` to `IC-weighting ACTIVE`.
2. **Remove the empty-IC early-return** at `strategy.py:1032`. (With seeds
   absent the loop still degrades to the raw composite via the
   `total_ic == 0.0` fallback — bit-identical to V221 behavior; verified as
   the IC-off control.)
3. **Make the per-regime path actually reachable:** declare
   `per_regime_ic_weighting: bool = True` on `VictoriaFeatures` (currently
   UNDECLARED — the startup banner has documented it as a silent no-op since
   V218), and fix a latent inertness: `_compute_weighted_conviction` reads
   `signals_dict.get("_regime")` from the **per-ticker** dict, which never
   carries `_regime` (it lives on the top-level signals dict) — so the regime
   lookup would silently fall back to pooled for every ticker. Fix: cache the
   cycle's consolidated regime label on the strategy in
   `_apply_regime_adaptive_thresholds` (which receives the top-level dict
   every cycle) and use it as the fallback label.

**fsum fences shipped in the same commit (V221's explicit instruction):**
- `_ic_weighted_composite` (`signal_generation.py:246,253`): `total_w` and
  `weighted_mean` are plain `sum()` over dict-iteration-ordered floats —
  dormant only while the decay-detector path falls back to equal-weight.
  Fence at activation, not after.
- `_compute_weighted_conviction` (`strategy.py:1083-1084`): the
  `weighted_sum`/`total_ic` `+=` accumulators iterate `signals_dict.items()`
  — the exact channel class V211/V220/V221 closed. This path is the one this
  version ACTIVATES, so it gets the same fence (collect terms → `math.fsum`).

NB: `signal_generation`'s `_ic_weighted_composite` itself remains on its
equal-weight fallback this version — it reads ICs from SignalDecayDetector
**observations** (needs ≥3 signals with ≥5 obs each), and the seeds carry no
obs. One bet per version: V222 activates the **conviction-filter** IC path
only. The fence is shipped dormant.

## Seeding rationale (sources per value)

"crypto signal effectiveness review" — the only first-party regime-stratified
edge measurement in the repo; the strategic audit's §1.1 verdict table quotes
it). **Caveat, stated honestly: its per-regime numbers are WIN RATES, not
Pearson ICs.** Per the V222 brief they are used directly as relative weight
