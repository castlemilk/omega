## The Anatomy of a Decentralized Prediction Market: Microstructure Evidence from the Polymarket Order Book
**Source:** arXiv 2604.24366 — https://arxiv.org/abs/2604.24366
**Type:** paper
**Score:** 4/5 × 3/5 = 12/25 — Queue

**Summary:** 30B tick-level events from Polymarket over 52 days, joined to on-chain `OrderFilled` events as ground truth. Documents a "longshot spread premium," geometric depth grids (not standard top-of-book), median wash-trade activity ~1% (upper tail 22%). Critical finding: trade direction inferred from the public WebSocket feed agrees with on-chain ground truth only ~59% of the time — i.e., conventional Lee-Ready / Kyle's-lambda inference is barely above coin-flip on Polymarket.

**Gap analysis:**
- Does Omega do this? Partial — Omega has a polymarket node (`omega/nodes/polymarket/`) but uses public feed data without on-chain reconciliation.
- What would change: polymarket signal pipeline; add on-chain `OrderFilled` ingestion to derive trade direction, then re-derive any imbalance / order-flow features.
- Dependencies: Polygon RPC access, contract ABI for Polymarket CTF Exchange, lightweight log indexer (Go-side). No new ML.

**Recommendation:** Worth queuing. Concrete first step: add `polymarket_onchain_fills` source under `omega/nodes/polymarket/` that subscribes (or polls) `OrderFilled` events and emits a per-market net buy/sell tape; wire into the existing polymarket signal node. Validate by comparing inferred-direction series vs. on-chain over a 1-day sample — if ≥30% disagreement reproduces, the upgrade is mandatory before any polymarket signal is trusted in training.

## Explainable Patterns in Cryptocurrency Microstructure
**Source:** arXiv 2602.00776 — https://arxiv.org/abs/2602.00776
**Type:** paper
**Score:** 4/5 × 2/5 = 8/25 — Watch

**Summary:** Binance Futures perpetuals (BTC, LTC, ETC, ENJ, ROSE), 1-second LOB+trades, Jan-2022 → Oct-2025. CatBoost + GMADL objective + SHAP. Key claim: feature rankings and partial-effect shapes are *stable across assets* despite heterogeneous liquidity. Top families: order-flow imbalance (monotone with concavity at extremes), spread (kills predictability), VWAP-to-mid asymmetry. Maker-vs-taker strategies diverge sharply during a flash crash — adverse-selection theory holds empirically.

**Gap analysis:**
- Does Omega do this? No. Per `project_omega.md`, Omega has zero L2 / order-book data — all 16+ signals are bar-level or on-chain.
- What would change: a brand-new "microstructure" signal node group (OFI, spread, VWAP-deviation features) and the streaming infra to feed it.
- Dependencies: WebSocket L2 feed from Binance/Bybit (geo-blocked — would need Coinbase/Kraken L2 instead), Go-side ring-buffer aggregator, 1s bar materializer.

**Recommendation:** Watch, don't build yet. The known gap "no order book / L2, all polling no streaming" is exactly what this paper would unlock, but lifting it requires streaming infra that's a multi-week project — premature given current Sharpe 1.82 ceiling is not obviously LOB-bound. Useful as the *justifying paper* whenever order-book infra gets prioritized; the SHAP shapes give a cheap target feature set (~10 features) rather than a black-box DeepLOB.
