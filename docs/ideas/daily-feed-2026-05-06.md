## From Hypotheses to Factors: Constrained LLM Agents in Cryptocurrency Markets

**Recommendation:** Strong fit — paper's "agent proposes, deterministic engine evaluates" pattern mirrors Omega's existing meta-analyst + hard-gate split. Concrete next step: prototype a `factor_agent` node that emits candidate signal recipes (ranked combinations of OHLCV/volatility/marketcap), execute via a sandboxed DSL, gate through `v49_gates`, and merge survivors into the meta-model ensemble.
