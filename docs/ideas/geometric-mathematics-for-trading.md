## 2. Gauge Theory and Arbitrage Geometry

### 2.1 Mathematical Foundation

This section draws on the Malaney-Weinstein gauge theory of economics (1996), Ilinski's gauge theory of finance (1997), and Farinelli's geometric arbitrage theory (2009). These are real, published mathematical frameworks — not speculation.

**The Setup: Financial Markets as Fiber Bundles**

A principal fiber bundle (P, M, G, π) consists of:
- **Base manifold M:** Time × Asset space. Each point (t, a) represents an asset at a given time.
- **Structure group G:** The group of numeraire transformations. Changing from USD pricing to BTC pricing is a gauge transformation g ∈ G.
- **Total space P:** The bundle of all possible "frames" for viewing asset values.
- **Projection π: P → M:** Maps each frame back to its base point.

**The Connection: Parallel Transport of Value**

A connection A on this bundle defines how to "parallel transport" asset values from one time to another. The Malaney-Weinstein connection encodes the idea that a self-financing portfolio is "constant" — it's being parallel-transported along its time trajectory.

Mathematically, the connection 1-form is:

```
A_μ = Σ_i w_i · d(log p_i) / dμ
```

where w_i are portfolio weights and p_i are asset prices, and μ indexes the base manifold directions.

**The Curvature: Arbitrage = Geometric Curvature**

The curvature 2-form F = dA + A ∧ A measures the failure of parallel transport to be path-independent. In financial terms:

```
F_μν = ∂_μ A_ν - ∂_ν A_μ + [A_μ, A_ν]
```

**Non-zero curvature F ≠ 0 means arbitrage exists.** Moving capital through a closed loop of trades returns more (or less) than you started with. The magnitude of F measures the *strength* of the arbitrage opportunity, and its direction tells you which loop to traverse.

### 2.2 Gauge Invariance in Crypto Markets

Certain observable quantities must be gauge-invariant (independent of numeraire choice). This is a powerful constraint:

- **BTC/ETH ratio:** Gauge-invariant. The relative performance of BTC vs ETH shouldn't depend on whether you measure in USD, USDT, or EUR.
- **Absolute BTC price in USD:** NOT gauge-invariant. It depends on your choice of numeraire.
- **Cross-exchange spreads:** Should be gauge-invariant after accounting for deposit/withdrawal costs.

**Practical implication for Victoria:** Any signal that depends on the absolute level of prices is gauge-dependent and potentially spurious. Signals built from *ratios*, *relative changes*, and *cross-correlations* are gauge-invariant and more likely to contain genuine alpha.

### 2.3 Curvature as Market Stress

The scalar curvature R = g^{μν} R_μν (the trace of the Ricci tensor) aggregates all the curvature information into a single number. In the gauge theory framework:

```
R_market = Tr(F_μν F^μν)
```

This is the Yang-Mills action functional. When R_market is large, the market is far from equilibrium (strong arbitrage forces, high stress). When R_market → 0, the market is efficiently pricing all assets.

**For Victoria:** Track R_market as a meta-signal. Rising curvature = opportunities. Falling curvature = mean-reversion/efficiency returning.

### 2.4 Algorithm: Gauge Curvature Estimator

```python
import numpy as np
from itertools import combinations

def estimate_gauge_curvature(prices: np.ndarray, dt: float = 1.0) -> np.ndarray:
    """
    Estimate the gauge curvature of a multi-asset price system.

    prices: (T, N) array of N asset prices over T timesteps
    Returns: (T-2,) array of scalar curvature estimates

    The curvature measures the path-dependence of value transport.
    Non-zero curvature = arbitrage opportunity.
    """
    T, N = prices.shape
    log_returns = np.diff(np.log(prices), axis=0)  # (T-1, N)

    # Connection coefficients: A_t^{ij} = d(log p_i)/dt - d(log p_j)/dt
    # This is the log-return differential between asset pairs
    curvatures = np.zeros(T - 2)

    for t in range(T - 2):
        F_total = 0.0
        for i, j in combinations(range(N), 2):
            # Discrete curvature: F_ij = ΔA_j/Δt_i - ΔA_i/Δt_j
            # In practice: how much does the i-j relationship change
            A_ij_t0 = log_returns[t, i] - log_returns[t, j]
            A_ij_t1 = log_returns[t + 1, i] - log_returns[t + 1, j]

            # Curvature component
            F_ij = (A_ij_t1 - A_ij_t0) / dt
            F_total += F_ij ** 2

        curvatures[t] = np.sqrt(F_total)

    return curvatures


def detect_arbitrage_loops(prices: np.ndarray, threshold: float = 0.001) -> list:
    """
    Detect triangular arbitrage opportunities via gauge curvature.

    For crypto: BTC/USDT → ETH/BTC → ETH/USDT should be consistent.
    Non-zero curvature around this loop = arbitrage.
    """
    T, N = prices.shape
    opportunities = []

    for t in range(T):
        for i, j, k in combinations(range(N), 3):
            # Check loop: i→j→k→i
            # If prices are consistent: p_ij * p_jk * p_ki = 1
            # Log deviation from unity = curvature
            if prices[t, i] > 0 and prices[t, j] > 0 and prices[t, k] > 0:
                loop = np.log(prices[t, j] / prices[t, i]) + \
                       np.log(prices[t, k] / prices[t, j]) + \
                       np.log(prices[t, i] / prices[t, k])
                if abs(loop) > threshold:
                    opportunities.append({
                        'time': t,
                        'assets': (i, j, k),
                        'curvature': loop,
                        'direction': 'forward' if loop > 0 else 'reverse'
                    })

    return opportunities
```

## 3. Chern-Simons Theory Applied to Markets

### 3.1 Mathematical Foundation

The Chern-Simons form, developed by Shiing-Shen Chern and Jim Simons in 1974, is a secondary characteristic class. For a connection A on a principal G-bundle over a 3-manifold M:

```
CS(A) = (k / 4π) ∫_M Tr(A ∧ dA + (2/3) A ∧ A ∧ A)
```

where k is the "level" (an integer for compact groups).

**Key properties:**
1. CS(A) is NOT gauge-invariant — it changes under gauge transformations. But exp(2πi · CS(A)) IS gauge-invariant.
2. CS(A) is a topological invariant: it doesn't depend on the metric of M, only on the topology.
3. Under a gauge transformation g: CS(A^g) = CS(A) + winding_number(g). The winding number is an integer.
4. CS(A) detects when a connection has undergone a topological twist that can't be continuously unwound.

### 3.2 Financial Interpretation: Regime Topology

**The 3-manifold:** Take M = Time × Signal₁ × Signal₂. This is a 3-dimensional space where one axis is time and two axes are signal values (e.g., momentum and volatility).

**The connection:** A encodes how nearby points in this 3D signal space are related. At each point, A tells you the local "drift" of the market state.

**The Chern-Simons invariant:** CS(A) measures the total topological "twist" of market dynamics in this 3D signal space.

**The critical insight:** When CS(A) changes by an integer, the market has undergone a topological phase transition — a regime shift that can't be smoothly reversed. This is fundamentally different from a curvature-based regime detector (which measures local stress). The Chern-Simons invariant detects *global* topological changes.

Analogy: Curvature tells you the road is curving. Chern-Simons tells you the road has twisted into a Möbius strip — you're now driving on the other side and no smooth deformation can fix it.

### 3.3 Discrete Chern-Simons for Financial Time Series

We can't compute the continuous integral, but we can discretize it. The key idea is to triangulate the 3D signal space and compute a lattice Chern-Simons invariant.

```python
import numpy as np
from scipy.spatial import Delaunay

def discrete_chern_simons(signal1: np.ndarray, signal2: np.ndarray,
                           window: int = 50) -> np.ndarray:
    """
    Compute a discrete Chern-Simons-like invariant for market regime detection.

    signal1, signal2: (T,) arrays of two signal time series
    window: lookback window for computing the invariant

    Returns: (T - window,) array of CS invariant estimates

    The CS invariant detects topological phase transitions in the
    (time, signal1, signal2) space that curvature alone cannot see.
    """
    T = len(signal1)
    cs_values = np.zeros(T - window)

    for t in range(window, T):
        # Extract window of data in 3D: (time, sig1, sig2)
        times = np.linspace(0, 1, window)
        s1 = signal1[t - window:t]
        s2 = signal2[t - window:t]

        # Normalize to unit cube
        s1_norm = (s1 - s1.min()) / (s1.max() - s1.min() + 1e-10)
        s2_norm = (s2 - s2.min()) / (s2.max() - s2.min() + 1e-10)

        points = np.column_stack([times, s1_norm, s2_norm])

        # Compute the "writhe" of the trajectory — a proxy for CS invariant
        # The writhe measures how much the curve wraps around itself
        cs = _compute_writhe(points)
        cs_values[t - window] = cs

    return cs_values


def _compute_writhe(curve: np.ndarray) -> float:
    """
    Compute the writhe of a 3D curve (discretized Gauss linking integral).

    Wr = (1/4π) ∫∫ (r1 - r2) · (dr1 × dr2) / |r1 - r2|³

    This is a topological invariant that measures the self-linking
    of the curve — how much it wraps around itself in 3D.
    """
    n = len(curve)
    writhe = 0.0

    for i in range(n - 1):
        for j in range(i + 2, n - 1):
            # Segments: curve[i]→curve[i+1] and curve[j]→curve[j+1]
            r1 = curve[i]
            r2 = curve[j]
            dr1 = curve[i + 1] - curve[i]
            dr2 = curve[j + 1] - curve[j]

            diff = r1 - r2
            norm = np.linalg.norm(diff)
            if norm < 1e-10:
                continue

            cross = np.cross(dr1, dr2)
            writhe += np.dot(diff, cross) / (norm ** 3)

    writhe /= (4 * np.pi)
    return writhe


def detect_topological_transitions(cs_series: np.ndarray,
                                     sensitivity: float = 0.5) -> list:
    """
    Detect points where the CS invariant jumps by ~integer values,
    indicating topological regime transitions.
    """
    transitions = []
    dcs = np.diff(cs_series)

    for t in range(len(dcs)):
        # Check if the change is close to an integer (topological quantization)
        nearest_int = round(dcs[t])
        if nearest_int != 0 and abs(dcs[t] - nearest_int) < sensitivity:
            transitions.append({
                'time': t,
                'cs_jump': dcs[t],
                'quantized_jump': nearest_int,
                'confidence': 1.0 - abs(dcs[t] - nearest_int) / sensitivity
            })

    return transitions
```

## 4. Riemannian Geometry of Signal Space

### 4.1 Mathematical Foundation

Treat Victoria's N signals at each timestep as a point in ℝ^N. Over time, these points trace a curve on an N-dimensional manifold. But this manifold isn't flat — its curvature is defined by the correlations between signals.

**The Metric Tensor:**

```
g_ij(t) = Cov(signal_i, signal_j) over a rolling window ending at t
```

This is a symmetric positive-definite (SPD) matrix at each time t. The set of all N×N SPD matrices forms a Riemannian manifold 𝒫_N with well-studied geometry.

**The Geodesic Distance:**

The geodesic distance between two correlation states Σ₁ and Σ₂ on 𝒫_N is:

```
d(Σ₁, Σ₂) = || log(Σ₁^{-1/2} Σ₂ Σ₁^{-1/2}) ||_F
```

where log is the matrix logarithm and ||·||_F is the Frobenius norm. This is the **affine-invariant Riemannian metric** (AIRM).

**Why this matters:** Euclidean distance between correlation matrices is meaningless (it doesn't respect the SPD constraint). The geodesic distance correctly measures how "far apart" two market regimes are in terms of signal relationships.

### 4.2 Curvature of Signal Space

**Scalar Curvature:**

The scalar curvature R at a point Σ on 𝒫_N is:

```
R = -N(N-1)(N+2) / 8
```

Wait — for the standard affine-invariant metric, the SPD manifold has *constant negative* curvature (it's a symmetric space). So the intrinsic curvature doesn't change. But this isn't the right question.

**The right question:** How does the *embedded* curvature of the trajectory Σ(t) through 𝒫_N change? This measures how rapidly the market's correlation structure is turning.

**Extrinsic Curvature of the Correlation Trajectory:**

```
κ(t) = || D²Σ/dt² ||_g / || DΣ/dt ||_g²
```

where D/dt is the covariant derivative along the trajectory and ||·||_g is the norm induced by the Riemannian metric at Σ(t).

When κ(t) is large: the correlation structure is rapidly changing direction → regime transition.
When κ(t) is small: the correlation structure is evolving smoothly → stable regime.

### 4.3 Geodesic Regression for Regime Prediction

Instead of linear regression in Euclidean space, we can do *geodesic regression* on 𝒫_N:

```
Σ(t) = Exp_{Σ₀}(t · V)
```

where Σ₀ is the initial correlation state, V is a tangent vector (the "velocity" of regime evolution), and Exp is the Riemannian exponential map.

This predicts where the correlation structure is heading *along the natural curves of the SPD manifold*, rather than along straight lines that might leave the manifold.

### 4.4 Algorithm: Riemannian Signal Space Monitor

```python
import numpy as np
from scipy.linalg import logm, expm, sqrtm, inv

def spd_geodesic_distance(Sigma1: np.ndarray, Sigma2: np.ndarray) -> float:
    """
    Compute the affine-invariant Riemannian distance between two SPD matrices.

    d(Σ₁, Σ₂) = || log(Σ₁^{-1/2} Σ₂ Σ₁^{-1/2}) ||_F
    """
    Sigma1_inv_sqrt = inv(sqrtm(Sigma1))
    M = Sigma1_inv_sqrt @ Sigma2 @ Sigma1_inv_sqrt
    return np.linalg.norm(logm(M), 'fro')


def spd_frechet_mean(matrices: list, max_iter: int = 50, tol: float = 1e-6) -> np.ndarray:
    """
    Compute the Fréchet mean (geometric center) of a set of SPD matrices.

    This is the Riemannian analog of the arithmetic mean, computed iteratively
    because the SPD manifold is curved.
    """
    N = matrices[0].shape[0]
    mean = np.mean(matrices, axis=0)  # Initialize with Euclidean mean

    for iteration in range(max_iter):
        # Compute tangent vectors from mean to each matrix
        mean_sqrt = sqrtm(mean)
        mean_inv_sqrt = inv(mean_sqrt)

        tangent_sum = np.zeros((N, N))
        for S in matrices:
            M = mean_inv_sqrt @ S @ mean_inv_sqrt
            tangent_sum += logm(M)

        tangent_avg = tangent_sum / len(matrices)

        # Check convergence
        if np.linalg.norm(tangent_avg, 'fro') < tol:
            break

        # Update mean via exponential map
        mean = mean_sqrt @ expm(tangent_avg) @ mean_sqrt

    return mean


def correlation_trajectory_curvature(signals: np.ndarray, window: int = 30,
                                       step: int = 1) -> np.ndarray:
    """
    Compute the extrinsic curvature of the correlation trajectory through SPD manifold.

    signals: (T, N) array of N signals over T timesteps
    window: rolling window for correlation estimation
    step: timestep between successive correlation matrices

    Returns: curvature at each point along the trajectory
    """
    T, N = signals.shape
    n_points = (T - window) // step

    # Compute sequence of correlation matrices
    corr_matrices = []
    for i in range(n_points):
        t = i * step + window
        chunk = signals[t - window:t]
        C = np.corrcoef(chunk.T)
        # Regularize to ensure SPD
        C = C + 1e-4 * np.eye(N)
        corr_matrices.append(C)

    # Compute geodesic velocities (finite differences in Riemannian sense)
    velocities = []
    for i in range(1, len(corr_matrices)):
        d = spd_geodesic_distance(corr_matrices[i-1], corr_matrices[i])
        velocities.append(d / step)

    # Compute curvature as rate of change of velocity direction
    curvatures = np.zeros(len(velocities) - 1)
    for i in range(1, len(velocities)):
        # Second-order geodesic distance (acceleration proxy)
        if i >= 2:
            d_prev = spd_geodesic_distance(corr_matrices[i-2], corr_matrices[i-1])
            d_curr = spd_geodesic_distance(corr_matrices[i-1], corr_matrices[i])
            d_skip = spd_geodesic_distance(corr_matrices[i-2], corr_matrices[i])

            # Triangle inequality violation measures curvature
            # On a flat space: d_skip = d_prev + d_curr (straight line)
            # On curved space: d_skip < d_prev + d_curr (geodesic bends)
            curvatures[i-1] = (d_prev + d_curr - d_skip) / (d_prev * d_curr + 1e-10)

    return curvatures


def regime_distance_matrix(signals: np.ndarray, window: int = 30,
                            n_regimes: int = 100) -> np.ndarray:
    """
    Compute the pairwise geodesic distance matrix between correlation states.

    Sample n_regimes equally-spaced correlation states and compute their
    Riemannian distances. The resulting distance matrix can be fed to
    spectral clustering or MDS for regime visualization.
    """
    T, N = signals.shape
    step = max(1, (T - window) // n_regimes)

    corr_matrices = []
    for i in range(0, T - window, step):
        chunk = signals[i:i + window]
        C = np.corrcoef(chunk.T) + 1e-4 * np.eye(N)
        corr_matrices.append(C)

    n = len(corr_matrices)
    dist_matrix = np.zeros((n, n))

    for i in range(n):
        for j in range(i + 1, n):
            d = spd_geodesic_distance(corr_matrices[i], corr_matrices[j])
            dist_matrix[i, j] = d
            dist_matrix[j, i] = d

    return dist_matrix
```

### 4.5 Riemannian Change Point Detection

Recent work (RIO-CPD, 2024) directly addresses correlation dynamics via Riemannian geometry for online change point detection. The core idea:

1. Maintain a running Fréchet mean of recent correlation matrices
2. Compute the geodesic distance from the current correlation to the mean
3. When this distance exceeds a threshold (calibrated via the chi-squared distribution on the tangent space), flag a regime change

```python
def riemannian_change_point_detector(signals: np.ndarray, window: int = 30,
                                       baseline_window: int = 200,
                                       threshold_percentile: float = 99.0) -> list:
    """
    Online regime change detection using Riemannian geometry of correlation matrices.

    Compares current correlation state to baseline Fréchet mean.
    Flags when geodesic distance exceeds adaptive threshold.
    """
    T, N = signals.shape
    change_points = []

    # Compute baseline correlation matrices
    baseline_corrs = []
    for t in range(window, min(baseline_window, T)):
        C = np.corrcoef(signals[t-window:t].T) + 1e-4 * np.eye(N)
        baseline_corrs.append(C)

    baseline_mean = spd_frechet_mean(baseline_corrs)

    # Compute baseline distances for threshold calibration
    baseline_distances = [spd_geodesic_distance(C, baseline_mean) for C in baseline_corrs]
    threshold = np.percentile(baseline_distances, threshold_percentile)

    # Online detection
    for t in range(baseline_window, T):
        C_current = np.corrcoef(signals[t-window:t].T) + 1e-4 * np.eye(N)
        d = spd_geodesic_distance(C_current, baseline_mean)

        if d > threshold:
            change_points.append({
                'time': t,
                'distance': d,
                'threshold': threshold,
                'severity': d / threshold
            })
            # Update baseline after detected change
            baseline_mean = C_current
            baseline_distances = [d]
            threshold = d * 1.5  # Temporary elevated threshold

    return change_points
```

## 5. Persistent Homology and Topological Data Analysis

### 5.1 Mathematical Foundation

Persistent homology is the flagship tool of Topological Data Analysis (TDA). It computes the topological features (connected components, loops, voids) of a point cloud at multiple scales and tracks which features "persist" across scales.

**The Setup:**

Given a point cloud X = {x₁, ..., x_n} ⊂ ℝ^d (e.g., recent signal vectors), build a filtration of simplicial complexes:

1. **Vietoris-Rips complex VR(X, ε):** Include a simplex [x_{i₀}, ..., x_{i_k}] if all pairwise distances d(x_{i_a}, x_{i_b}) ≤ ε.
2. **Filtration:** As ε increases from 0 to ∞, VR(X, ε) grows from discrete points to a single blob.
3. **Homology:** At each ε, compute the homology groups H_k(VR(X, ε)):
   - H₀ = connected components (clusters)
   - H₁ = loops (cycles in the data)
   - H₂ = voids (enclosed cavities)

**Persistence:** A topological feature (component, loop, void) is "born" at εᵇ and "dies" at εᵈ. The persistence εᵈ - εᵇ measures how robust the feature is. Short-lived features = noise. Long-lived features = genuine structure.

**Betti numbers:** β_k(ε) = rank(H_k(VR(X, ε))) = number of k-dimensional holes at scale ε.

**Persistence diagrams:** Plot each feature as a point (εᵇ, εᵈ) in the birth-death plane. Points far from the diagonal are topologically significant.

### 5.2 Why TDA for Market Structure

Traditional signal analysis assumes a fixed metric structure (e.g., Euclidean distance, correlation). TDA is invariant to:

- Monotone transformations of individual signals (it only cares about the topology of the point cloud, not the coordinates)
- Noise (short-lived topological features are filtered out via persistence)
- Dimensionality (works in any dimension without curse-of-dimensionality issues for topology)

**What changes in topology tell you:**

| Topological Change | Market Interpretation |
|---|---|
| β₀ increases (new component) | Market is fragmenting — signals are decorrelating into separate clusters |
| β₀ decreases (components merge) | Market is consolidating — previously independent signals are coupling |
| β₁ increases (new loop) | A cyclical pattern has emerged in signal space (mean-reversion regime) |
| β₁ decreases (loop dies) | A cyclical pattern has broken down (trend/breakout regime) |
| β₂ increases (new void) | A hollow region in signal space — the market is avoiding certain state combinations |

### 5.3 Persistence Landscapes for Time Series

A persistence landscape converts a persistence diagram into a functional representation that can be averaged, compared, and fed into ML models.

The k-th landscape function λ_k(t) is the k-th largest value of the "tent function" max(0, min(t - b_i, d_i - t)) across all persistence intervals [b_i, d_i].

**Key property:** The L^p norms ||λ_k||_p show strong growth 200-250 trading days before major market crashes (documented in Gidea & Katz, 2018).

### 5.4 Algorithm: TDA Signal Monitor

```python
import numpy as np

# Requires: pip install ripser persim scikit-tda
# For production, consider giotto-tda which has better performance

def compute_persistence_features(signals: np.ndarray, window: int = 50,
                                   max_dim: int = 2) -> dict:
    """
    Compute persistent homology features for a window of signal vectors.

    signals: (window, N) array of N signals over window timesteps
    max_dim: maximum homology dimension to compute

    Returns dict with Betti numbers, persistence statistics, and landscape norms.
    """
    try:
        from ripser import ripser
        from persim import PersistenceLandscapeExact
    except ImportError:
        # Fallback: simplified Betti number estimation via distance matrix
        return _fallback_topology(signals, max_dim)

    # Compute persistence diagrams
    result = ripser(signals, maxdim=max_dim)
    diagrams = result['dgms']

    features = {}

    for dim in range(max_dim + 1):
        dgm = diagrams[dim]
        # Remove infinite death times
        finite_dgm = dgm[np.isfinite(dgm[:, 1])]

        if len(finite_dgm) == 0:
            features[f'betti_{dim}'] = 0
            features[f'persistence_mean_{dim}'] = 0.0
            features[f'persistence_max_{dim}'] = 0.0
            features[f'persistence_std_{dim}'] = 0.0
            features[f'landscape_L1_{dim}'] = 0.0
            features[f'landscape_L2_{dim}'] = 0.0
            continue

        persistences = finite_dgm[:, 1] - finite_dgm[:, 0]

        # Betti number at median scale
        median_scale = np.median(finite_dgm[:, 1])
        alive_at_median = np.sum((finite_dgm[:, 0] <= median_scale) &
                                  (finite_dgm[:, 1] > median_scale))

        features[f'betti_{dim}'] = alive_at_median
        features[f'persistence_mean_{dim}'] = np.mean(persistences)
        features[f'persistence_max_{dim}'] = np.max(persistences)
        features[f'persistence_std_{dim}'] = np.std(persistences)

        # Landscape norms (L1 and L2)
        features[f'landscape_L1_{dim}'] = np.sum(persistences)
        features[f'landscape_L2_{dim}'] = np.sqrt(np.sum(persistences ** 2))

    # Persistence entropy (information content of topology)
    all_pers = np.concatenate([diagrams[d][:, 1] - diagrams[d][:, 0]
                                for d in range(max_dim + 1)
                                if len(diagrams[d]) > 0])
    all_pers = all_pers[np.isfinite(all_pers) & (all_pers > 0)]
    if len(all_pers) > 0:
        p = all_pers / all_pers.sum()
        features['persistence_entropy'] = -np.sum(p * np.log(p + 1e-10))
    else:
        features['persistence_entropy'] = 0.0

    return features


def _fallback_topology(signals: np.ndarray, max_dim: int) -> dict:
    """
    Estimate topological features without ripser using distance matrix analysis.
    Uses connected components via threshold on distance matrix.
    """
    from scipy.spatial.distance import pdist, squareform
    from scipy.sparse.csgraph import connected_components

    D = squareform(pdist(signals))
    features = {}

    # Estimate Betti_0 at multiple scales
    scales = np.percentile(D[D > 0], [25, 50, 75])
    for i, eps in enumerate(scales):
        adj = (D <= eps).astype(int)
        n_components, _ = connected_components(adj)
        features[f'betti_0_scale_{i}'] = n_components

    # Estimate Betti_1 via first Betti number of the Rips graph
    # at median scale (number of independent cycles = edges - vertices + components)
    median_eps = scales[1]
    adj = (D <= median_eps).astype(int)
    np.fill_diagonal(adj, 0)
    n_edges = adj.sum() // 2
    n_vertices = len(signals)
    n_comp, _ = connected_components(adj)
    features['betti_1_estimate'] = max(0, n_edges - n_vertices + n_comp)

    return features


def rolling_topology_monitor(signals: np.ndarray, window: int = 50,
                               step: int = 5) -> list:
    """
    Compute topological features over rolling windows.
    Detects when the topology of signal space changes.

    signals: (T, N) array
    Returns: list of feature dicts with timestamps
    """
    T, N = signals.shape
    results = []

    for t in range(window, T, step):
        chunk = signals[t - window:t]

        # Standardize within window
        chunk_std = (chunk - chunk.mean(axis=0)) / (chunk.std(axis=0) + 1e-10)

        features = compute_persistence_features(chunk_std, window)
        features['time'] = t
        results.append(features)

    return results


def detect_topological_regime_shift(topology_series: list,
                                      lookback: int = 20) -> list:
    """
    Detect regime shifts by monitoring changes in topological features.

    A regime shift is detected when Betti numbers or persistence statistics
    change significantly relative to their recent history.
    """
    shifts = []

    if len(topology_series) < lookback + 1:
        return shifts

    feature_keys = [k for k in topology_series[0].keys() if k != 'time']

    for i in range(lookback, len(topology_series)):
        current = topology_series[i]
        recent = topology_series[i - lookback:i]

        anomaly_score = 0.0
        anomaly_details = {}

        for key in feature_keys:
            values = [r[key] for r in recent]
            mean_val = np.mean(values)
            std_val = np.std(values) + 1e-10

            z_score = abs(current[key] - mean_val) / std_val
            if z_score > 2.5:
                anomaly_score += z_score
                anomaly_details[key] = {
                    'z_score': z_score,
                    'current': current[key],
                    'mean': mean_val,
                    'std': std_val
                }

        if anomaly_score > 5.0:  # Multiple features changing simultaneously
            shifts.append({
                'time': current['time'],
                'anomaly_score': anomaly_score,
                'details': anomaly_details
            })

    return shifts
```

### 5.5 Early Warning via Persistence Norms

The L^p norms of persistence landscapes have been empirically shown to provide early warning of financial crashes:

```python
def crash_early_warning(signals: np.ndarray, window: int = 50,
                         lookback: int = 250, p_norm: float = 2.0) -> np.ndarray:
    """
    Compute persistence landscape L^p norms as crash early warning signal.

    Literature suggests strong growth in L^p norms ~250 trading days
    before major crashes (adapted for crypto: ~250 candles at chosen timeframe).

    Returns: (T,) array of warning levels (0 = calm, higher = increasing risk)
    """
    topology_series = rolling_topology_monitor(signals, window, step=1)

    # Extract landscape L2 norms for H1 (loop topology)
    l2_norms = np.array([t.get('landscape_L2_1', 0.0) for t in topology_series])

    if len(l2_norms) < lookback:
        return np.zeros(len(l2_norms))

    # Compute rolling growth rate of L^p norms
    warning_level = np.zeros(len(l2_norms))

    for i in range(lookback, len(l2_norms)):
        recent = l2_norms[i - lookback:i]

        # Fit linear trend to log of L^p norms
        t_axis = np.arange(lookback)
        log_norms = np.log(recent + 1e-10)

        # Simple linear regression for growth rate
        slope = np.polyfit(t_axis, log_norms, 1)[0]

        # Warning level = exponential growth rate of topological complexity
        warning_level[i] = max(0, slope)

    return warning_level
```

geometric_signals.py — Geometric Mathematics Layer for Victoria

Combines Riemannian geometry, TDA, gauge theory, and Chern-Simons

import numpy as np
from dataclasses import dataclass, field
from typing import Optional

@dataclass
class GeometricState:
    """Current state of all geometric signals."""
    timestamp: float

    # Riemannian
    geodesic_distance_from_baseline: float = 0.0

    cs_jump_magnitude: float = 0.0


class GeometricSignalEngine:
    """
    Main engine that computes all geometric signals from Victoria's raw signals.

    Usage:
        engine = GeometricSignalEngine(n_signals=14, window=50)

        for signals_t in signal_stream:
            engine.update(signals_t)

            if state.regime_transition_detected:
                # Adjust position sizing, re-evaluate signals
                pass

                # Reduce exposure
                pass

                 corr_window: int = 30,

                 baseline_window: int = 200):

        self.corr_window = corr_window
        self.tda_window = tda_window
        self.cs_window = cs_window
        self.baseline_window = baseline_window

        # Signal buffer
        self.signal_buffer = []
        self.max_buffer = max(baseline_window, tda_window, cs_window) + 100

        # Riemannian state
        self.baseline_mean = None
        self.baseline_distances = []
        self.regime_threshold = None

        # TDA state
        self.topology_history = []

        # Chern-Simons state
        self.cs_history = []

        # Gauge state
        self.curvature_history = []

    def update(self, signal_vector: np.ndarray):
        """Process a new signal vector and update all geometric states."""
        assert len(signal_vector) == self.n_signals
        self.signal_buffer.append(signal_vector)

        # Trim buffer
        if len(self.signal_buffer) > self.max_buffer:
            self.signal_buffer = self.signal_buffer[-self.max_buffer:]

    def get_state(self) -> GeometricState:
        """Compute and return current geometric state."""
        signals = np.array(self.signal_buffer)
        T = len(signals)

        state = GeometricState(timestamp=T)

        if T < self.corr_window + 2:
            return state  # Not enough data yet

        # --- Riemannian signals ---
        state = self._compute_riemannian(signals, state)

        # --- TDA signals ---
        if T >= self.tda_window:
            state = self._compute_tda(signals, state)

        # --- Chern-Simons signals ---
        if T >= self.cs_window and self.n_signals >= 2:
            state = self._compute_chern_simons(signals, state)

        # --- Gauge curvature ---
        if T >= 3:
            state = self._compute_gauge(signals, state)

        return state

    def _compute_riemannian(self, signals: np.ndarray,
                              state: GeometricState) -> GeometricState:
        """Compute Riemannian geometry signals."""
        from scipy.linalg import logm, sqrtm, inv

        T = len(signals)
        N = self.n_signals

        # Current correlation matrix
        chunk = signals[-self.corr_window:]
        C_current = np.corrcoef(chunk.T) + 1e-4 * np.eye(N)

        # Initialize baseline if needed
        if self.baseline_mean is None and T >= self.baseline_window:
            baseline_corrs = []
            for t in range(self.corr_window, min(self.baseline_window, T)):
                c = np.corrcoef(signals[t-self.corr_window:t].T) + 1e-4 * np.eye(N)
                baseline_corrs.append(c)
            self.baseline_mean = np.mean(baseline_corrs, axis=0)  # Simplified

        if self.baseline_mean is not None:
            try:
                d = spd_geodesic_distance(C_current, self.baseline_mean)
                state.geodesic_distance_from_baseline = d

                self.baseline_distances.append(d)
                if len(self.baseline_distances) > 100:
                    threshold = np.percentile(self.baseline_distances[-100:], 95)
                    state.regime_transition_detected = d > threshold
            except Exception:
                pass  # Matrix computation can fail; degrade gracefully

        # Trajectory curvature (needs 3+ correlation states)
        if T >= self.corr_window + 3:
            try:
                C_prev2 = np.corrcoef(signals[-self.corr_window-2:-2].T) + 1e-4 * np.eye(N)
                C_prev1 = np.corrcoef(signals[-self.corr_window-1:-1].T) + 1e-4 * np.eye(N)

                d1 = spd_geodesic_distance(C_prev2, C_prev1)
                d2 = spd_geodesic_distance(C_prev1, C_current)
                d_skip = spd_geodesic_distance(C_prev2, C_current)

                state.correlation_trajectory_curvature = \
                    (d1 + d2 - d_skip) / (d1 * d2 + 1e-10)
            except Exception:
                pass

        return state

    def _compute_tda(self, signals: np.ndarray,
                      state: GeometricState) -> GeometricState:
        """Compute topological data analysis signals."""
        chunk = signals[-self.tda_window:]
        chunk_std = (chunk - chunk.mean(axis=0)) / (chunk.std(axis=0) + 1e-10)

        features = compute_persistence_features(chunk_std, self.tda_window)

        state.betti_0 = features.get('betti_0', 1)
        state.betti_1 = features.get('betti_1', 0)
        state.betti_2 = features.get('betti_2', 0)
        state.persistence_entropy = features.get('persistence_entropy', 0.0)
        state.landscape_l2_norm = features.get('landscape_L2_1', 0.0)

        # Track topology history for shift detection
        self.topology_history.append(features)
        if len(self.topology_history) > 50:
            self.topology_history = self.topology_history[-50:]

        if len(self.topology_history) >= 20:
            shifts = detect_topological_regime_shift(self.topology_history, lookback=15)
            state.topology_shift_detected = len(shifts) > 0

        return state

    def _compute_chern_simons(self, signals: np.ndarray,
                                state: GeometricState) -> GeometricState:
        """Compute Chern-Simons invariant signals."""
        # Use the two most volatile signals for the CS computation
        recent = signals[-self.cs_window:]
        volatilities = np.std(recent, axis=0)
        top2 = np.argsort(volatilities)[-2:]

        cs = discrete_chern_simons(
            signals[:, top2[0]], signals[:, top2[1]],
            window=self.cs_window
        )

        if len(cs) > 0:
            state.writhe_invariant = cs[-1]
            self.cs_history.append(cs[-1])

            if len(self.cs_history) > 2:
                dcs = self.cs_history[-1] - self.cs_history[-2]
                nearest_int = round(dcs)
                if nearest_int != 0 and abs(dcs - nearest_int) < 0.5:
                    state.topological_transition = True
                    state.cs_jump_magnitude = abs(dcs)

        return state

    def _compute_gauge(self, signals: np.ndarray,
                        state: GeometricState) -> GeometricState:
        """Compute gauge theory signals."""
        # Use prices if available (first few signals assumed price-like)
        # Otherwise use signal values directly
        prices = signals[-10:]  # Short window for curvature

        curvatures = estimate_gauge_curvature(prices)
        if len(curvatures) > 0:
            state.market_curvature = curvatures[-1]

        return state
